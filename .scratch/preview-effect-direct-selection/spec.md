# 实时预览直接选择特效片段

Status: ready-for-agent

## Problem Statement

当前用户只能先在特效轨道中选中特效片段，实时预览画布才会显示对应的特效选区并允许拖拽调整。当同一个播放头下同时生效多个特效片段时，用户需要在多条特效轨道中寻找目标，难以准确选中想要调整的特效，降低了过程预览的直观性和编辑效率。

## Solution

在实时预览画布增加特效命中选择层。用户可以直接点击当前播放头下实际生效的特效边界框来选中特效片段，并立即复用现有的特效选区、位置拖拽、四角缩放和属性面板联动能力。

当多个特效片段的边界框发生重叠时，点击优先命中渲染层级最上方的特效；需要选择被遮挡的特效时，用户仍可通过特效轨道选择。点击预览空白区域取消选择。普通点击只改变选择，超过移动阈值后才启动位置拖拽；缩放继续使用现有控制点。

## User Stories

1. 作为特效编辑者，我希望直接点击实时预览中出现的特效来选中特效片段，以便无需先在特效轨道中寻找目标。
2. 作为特效编辑者，我希望点击特效的边界框空白区域也能选中它，以便不必精确点击文字、图形或动画的实际像素。
3. 作为特效编辑者，我希望只有当前播放头处于生效区间的特效片段才可以从预览中被选中，以便预览中的可选对象与当前画面一致。
4. 作为特效编辑者，我希望播放头处于特效片段起始帧时就可以从预览选中它，以便不需要额外播放一帧。
5. 作为特效编辑者，我希望播放头处于特效片段结束帧时不能从预览选中它，以便选择边界与特效实际生效边界一致。
6. 作为特效编辑者，我希望点击重叠特效时优先选中最上层特效，以便点击结果与画面视觉层级一致。
7. 作为特效编辑者，我希望仍然可以通过特效轨道选中被遮挡的特效，以便在画面重叠时仍能调整底层对象。
8. 作为特效编辑者，我希望从预览选中特效后对应的特效轨道片段同步高亮，以便明确当前编辑对象。
9. 作为特效编辑者，我希望从预览选中特效后右侧属性面板同步切换，以便立即进行参数调整。
10. 作为特效编辑者，我希望从预览选中特效后显示已有的特效选区和控制点，以便继续进行位置和尺寸调整。
11. 作为特效编辑者，我希望点击预览空白区域可以取消当前选择，以便快速结束当前特效编辑状态。
12. 作为特效编辑者，我希望点击特效但不移动鼠标时只执行选择，以便普通点击不会意外改变特效位置。
13. 作为特效编辑者，我希望按住预览中的特效并移动超过拖拽阈值后才开始移动，以便区分选择手势和拖拽手势。
14. 作为特效编辑者，我希望直接从预览选中特效后可以拖动其位置，以便选择和调整可以连续完成。
15. 作为特效编辑者，我希望移动期间实际特效、特效选区和属性面板实时同步，以便能看到过程预览反馈。
16. 作为特效编辑者，我希望拖动预览中特效的位置不会超出画布边界，以便结果始终是合法布局。
17. 作为特效编辑者，我希望特效缩放继续通过现有四角控制点完成，以便已有的尺寸调整习惯不被改变。
18. 作为特效编辑者，我希望一次预览位置拖拽最终只产生一条编辑历史，以便可以用一次撤销恢复整次调整。
19. 作为特效编辑者，我希望预览选择不会改变特效片段的起始帧、持续时间或所在特效轨道，以便本功能只解决画布选择问题。
20. 作为特效编辑者，我希望特效轨道原有的选择、移动和裁剪行为保持不变，以便预览入口是补充而不是替代。
21. 作为特效编辑者，我希望没有视频素材、只有特效片段时预览选择仍然有效，以便特效编辑不依赖主视频轨道。
22. 作为特效编辑者，我希望横屏、竖屏和方形项目中的预览命中位置都与画布比例一致，以便不同画布方向下选择行为一致。

## Implementation Decisions

- 以实时预览画布作为预览直接选择的主要交互 seam，命中层负责把画面坐标映射为当前播放头下的特效片段选择结果。
- 预览命中层只检查当前播放头处于生效区间的特效片段；生效区间继续使用左闭右开规则，起始帧可选，结束帧不可选。
- 命中范围使用特效参数中的现有位置和尺寸边界框，包括边界框内的透明区域，不进行实际像素级命中检测。
- 多个候选边界框重叠时，按预览渲染顺序从上到下进行命中，优先返回最上层特效片段；特效轨道仍是选择被遮挡特效的备用入口。
- 预览选择只通过现有页面层选择回调更新当前选中特效片段；页面层继续负责同步特效轨道高亮、属性面板和特效选区。
- 预览空白点击清除当前特效片段选择；点击预览控制栏、时间轴或其他工作区元素不应被预览命中层拦截。
- 命中层与现有特效选区保持分层：命中层负责未选中特效的选择，选区层继续负责已选中特效的边界框、位置移动和四角缩放。
- 普通点击只选择特效；只有指针相对按下位置移动超过既定拖拽阈值后，才启动位置拖拽。拖拽期间继续使用现有过程预览临时快照通道，松开后只提交一次最终参数变化。
- 预览直接选择不改变项目数据模型、特效参数契约、时间轴范围、特效轨道布局、播放头、预览与导出的共享渲染定义或导出协议。
- 预览命中使用画布的实际显示尺寸与项目坐标之间的比例换算，保证横屏、竖屏和方形项目的边界框命中一致。
- 特效片段不存在有效位置或尺寸参数时不作为预览命中候选，保持现有模板参数归一化和异常兜底行为。
- 预览选择不新增锁定、吸附、像素级命中、循环选择被遮挡对象、键盘选择或新的撤销模型。
- 所有新增函数、命中排序逻辑、坐标换算和手势状态转换使用中文注释，说明预览选择状态与正式编辑状态的边界。

## Testing Decisions

- 测试验证用户可观察行为：预览点击后的当前选择、特效轨道高亮、属性面板切换、选区显示、空白取消和后续拖拽结果；不锁定具体 DOM 层级、内部 ref 或事件监听器数量。
- 在预览画布交互 seam 测试：单个生效特效的边界框点击、透明区域点击、非生效特效不可命中、起始帧/结束帧边界，以及横屏、竖屏和方形画布的坐标映射。
- 在重叠命中行为测试：多个生效特效边界框重叠时返回最上层特效；改变渲染顺序后命中结果随顺序变化；未命中的底层特效仍可通过特效轨道选择。
- 在选择联动测试：预览选择通过页面层更新特效片段 ID，特效轨道和属性面板显示同一特效；预览空白选择清除当前特效片段。
- 在手势行为测试：按下后无移动只选择；移动未超过阈值不提交位置；超过阈值后位置过程预览跟随鼠标；松开后有变化时只提交一次参数更新。
- 在画布编辑回归测试：从预览直接选中特效后可继续使用现有位置拖拽和四角缩放，边界限制、最小尺寸、临时快照和一次性撤销语义保持不变。
- 在事件隔离测试：点击预览控制栏、时间轴和属性面板不会被命中层错误选中特效或阻断原有交互；预览空白点击不会影响播放头或其他工作区状态。
- 继续复用现有预览画布、画布选区、编辑器页面、时间轴和编辑器历史测试夹具；新增公开坐标/排序辅助函数使用纯行为测试，组件测试使用用户事件和回调断言。
- 完成单文件测试、类型检查、构建和完整测试套件；实现完成后使用代码审查技能检查项目规范和本规格符合度。

## Out of Scope

- 不实现像素级透明度命中或读取 Remotion 实际渲染像素。
- 不实现点击循环选择被遮挡的底层特效；底层对象继续通过特效轨道选择。
- 不实现锁定特效、隐藏特效、键盘修饰键选择或多选。
- 不实现选择非当前播放头生效区间的特效，也不自动跳转播放头。
- 不改变特效模板视觉实现、参数声明、项目数据模型、时间轴时间范围或特效轨道布局。
- 不改变现有缩放控制点、属性面板编辑、撤销重做、自动保存或导出流程。
- 不增加辅助线、吸附、键盘微调、`Esc` 取消或新的拖拽取消机制。

## Further Notes

- 本规格补充实时预览特效拖拽过程反馈和未生效时间段交互限制，核心目标是实现“看到效果再选择”。
- 本规格遵循 ADR-0018 的三栏编辑器布局、ADR-0020 的画布与参数面板结合调整方式，以及 ADR-0016 的基础撤销重做和自动保存约束。
- 本功能是可逆的显示层交互改进，不引入新的持久化协议、跨模块架构取舍或领域模型变化，因此不新增 ADR。
- 规格确认后即可进入实现；实现期间保留工作区中与本功能无关的既有改动。
