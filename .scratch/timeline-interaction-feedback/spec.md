# 时间轴实时交互与剪贴板操作

Status: resolved

## Problem Statement

当前模板化特效编辑器的时间轴在片段移动、片段裁剪和播放头定位过程中缺少实时反馈。片段的鼠标移动只在松开后才更新项目快照，预览画布无法展示拖动中的临时结果；播放头只能通过点击定位，不能按住鼠标连续拖动。时间轴还缺少针对视频片段和特效片段的复制粘贴快捷键，用户难以快速复用已有的特效片段或视频片段。

## Solution

让时间轴支持基于左键按下、移动、松开的实时编辑手势：视频片段和特效片段在拖动或裁剪过程中严格跟随鼠标并按帧吸附，预览画布同步展示临时项目状态；播放头和顶部时间标尺支持连续拖动，轨道空白处点击可直接定位。鼠标松开时将一次实际发生的片段编辑作为一个完整历史步骤提交，支持 `Ctrl+Z` 撤销和 `Ctrl+Y` 重做。

同时增加时间轴范围内的 `Ctrl+C` / `Ctrl+V`：复制当前选中的视频片段或特效片段，粘贴到当前播放头位置，生成新的片段 ID，并根据轨道约束选择合法位置。复制不产生历史，粘贴作为一次完整编辑产生一条历史记录。输入控件保留浏览器原生快捷键行为。

## User Stories

1. 作为视频编辑者，我希望按住视频片段并拖动时片段立即跟随鼠标，以便准确判断新的时间位置。
2. 作为视频编辑者，我希望视频片段移动按整数帧吸附，以便编辑结果与项目帧率保持一致。
3. 作为视频编辑者，我希望拖动视频片段时预览画布实时更新，以便确认片段移动后当前画面的变化。
4. 作为视频编辑者，我希望拖动视频片段的左右边缘时持续看到新的片段长度，以便精确裁剪视频。
5. 作为视频编辑者，我希望视频片段不会与主视频轨道上的其他视频片段重叠，以便项目始终符合主视频轨道约束。
6. 作为视频编辑者，我希望发生视频片段冲突时自动吸附到最近的合法边界，以便松开鼠标后不需要处理延迟错误。
7. 作为特效编辑者，我希望按住特效片段并拖动时片段立即跟随鼠标，以便准确控制特效片段的生效时间。
8. 作为特效编辑者，我希望拖动或裁剪特效片段时预览画布实时展示临时特效结果，以便确认时间范围是否正确。
9. 作为特效编辑者，我希望重叠的特效片段可以共存，并在必要时自动排列到不同特效轨道，以便多个特效可以同时生效。
10. 作为编辑者，我希望拖动片段时不使用额外缓动，鼠标停下后片段立即停在对应帧，以便获得可预测的编辑反馈。
11. 作为编辑者，我希望拖动片段后松开鼠标才提交变更，以便一次拖动只产生一次编辑历史记录。
12. 作为编辑者，我希望没有实际移动或裁剪变化时不产生历史记录，以便撤销栈不出现无效步骤。
13. 作为编辑者，我希望按 `Ctrl+Z` 撤销最近一次片段移动、裁剪或粘贴，以便快速恢复误操作。
14. 作为编辑者，我希望按 `Ctrl+Y` 重做刚刚撤销的片段编辑，以便恢复被撤销的操作。
15. 作为编辑者，我希望点击时间标尺或轨道空白处可以定位播放头，以便快速查看项目中的任意时间点。
16. 作为编辑者，我希望按住鼠标左键拖动播放头或时间标尺时预览画布实时更新，以便连续浏览视频内容。
17. 作为编辑者，我希望播放头定位不会污染项目编辑历史，以便 `Ctrl+Z` 只处理实际的项目内容编辑。
18. 作为编辑者，我希望点击片段仍然用于选择片段，片段拖动仍然用于移动片段，以便播放头定位不会与片段操作冲突。
19. 作为编辑者，我希望复制当前选中的视频片段或特效片段，以便复用已有编辑内容。
20. 作为编辑者，我希望将复制的片段粘贴到当前播放头位置，以便快速在目标时间点创建副本。
21. 作为编辑者，我希望粘贴后的片段保留原片段的时长、特效参数和媒体引用，以便副本与原片段表现一致。
22. 作为编辑者，我希望粘贴后的片段拥有新的唯一 ID，以便副本可以独立移动、裁剪、删除和保存。
23. 作为编辑者，我希望粘贴特效片段时系统自动分配可用特效轨道，以便副本不会破坏特效轨道布局。
24. 作为编辑者，我希望粘贴视频片段时系统自动避开主视频轨道上的重叠位置，以便粘贴结果始终是合法编辑项目。
25. 作为编辑者，我希望粘贴完成后新片段自动被选中，以便立即继续调整其参数或时间范围。
26. 作为编辑者，我希望在没有选中片段时复制不产生任何变化，以便快捷键不会创建无意义的内容。
27. 作为属性编辑者，我希望在文字框、数字框或其他输入控件中使用系统原生的复制、粘贴、撤销和重做，以便编辑参数时快捷键不会被时间轴抢占。
28. 作为编辑者，我希望时间轴无需在拖动到可视区域边缘时自动横向滚动，以便当前版本的拖动行为保持稳定可预测。

## Implementation Decisions

- 时间轴继续由显示层负责渲染项目快照，页面层负责协调项目状态、临时预览状态和编辑器公共命令。
- 片段拖动和裁剪采用“手势开始快照、手势期间临时状态、手势结束提交”的状态模型。手势期间不向持久化项目历史写入每一帧变化。
- 临时项目状态必须同时驱动时间轴和预览画布，使片段位置、片段长度、当前播放头和画面结果保持一致。
- 片段移动、右侧裁剪和左侧裁剪都以整数帧为单位；起始帧不能小于零，持续时间至少为一帧。
- 播放头和时间标尺拖动只改变页面级当前播放帧，不进入编辑项目历史，也不触发项目快照提交。
- 时间标尺和播放头是播放头拖动入口；轨道空白处点击直接定位；片段自身的鼠标操作优先用于选择、移动或裁剪。
- 片段拖动不使用缓动动画，视觉位置与当前鼠标对应的吸附帧保持同步。
- 主视频轨道继续禁止视频片段重叠。移动或裁剪过程中应计算最近的合法边界，提交时保证项目快照通过领域校验。
- 特效片段允许时间范围重叠，布局层根据重叠关系将其排列到不同特效轨道；当前范围不包含通过垂直拖动改变特效轨道。
- 调整片段位置或长度必须使用一次原子化编辑操作，确保一次 `Ctrl+Z` 能同时恢复起始帧和持续时间；不能通过删除后新增的两个独立历史命令模拟裁剪。
- 只有最终位置或长度与手势开始时不同，才创建历史记录；无变化的鼠标手势不创建记录。
- `Ctrl+Z` 调用编辑器撤销，`Ctrl+Y` 调用编辑器重做。快捷键只在焦点不属于输入框、选择框、文本域或可编辑内容时接管。
- 复制操作只保存当前选中的一个视频片段或特效片段，不创建历史记录；剪贴板数据应为可安全复制的片段快照，而不是对原项目对象的可变引用。
- 粘贴位置使用粘贴触发时的当前播放头帧，并保留原片段的时长、特效参数、媒体引用及其他业务属性；粘贴副本必须生成新的唯一 ID。
- 粘贴视频片段时遵循主视频轨道不重叠约束；粘贴特效片段时选择可用特效轨道。若目标位置冲突，按既定合法位置规则调整，而不是提交非法项目。
- 粘贴成功后选中新片段，并将整次粘贴作为一条历史记录；没有可复制内容时粘贴无操作。
- 不增加 `Esc` 取消当前手势，也不增加拖动到时间轴可视边缘时的自动横向滚动。
- 现有顶部撤销和重做按钮继续可用，键盘快捷键与按钮共用同一编辑器历史。
- 实现和新增测试中的函数、复杂状态转换及关键交互边界应补充中文注释，方便维护者理解临时状态与提交状态的区别。

## Testing Decisions

- 测试应验证用户可观察的行为：事件发生后的位置、长度、播放头、预览帧、选择状态、项目快照和历史结果；不锁定具体内部 ref、事件监听器数量或实现细节。
- 在时间轴组件接缝测试：左键按下/移动/松开期间的实时临时位置，视频和特效片段的移动与左右裁剪，整数帧吸附，零时长和负帧边界，标尺/播放头拖动，轨道空白定位，点击片段与播放头操作的区分，以及无变化手势不产生提交事件。
- 在编辑器命令和编辑器历史接缝测试：移动、裁剪和复制粘贴的原子性；一次撤销完整恢复一次编辑；`Ctrl+Y` 恢复被撤销的编辑；新编辑清空重做栈；剪贴副本具有新 ID且保留业务字段。
- 在领域约束接缝测试：视频片段移动或粘贴不会产生重叠；视频片段只能落在非负帧；片段持续时间始终为正；特效重叠后能够被布局到不同特效轨道。
- 在编辑器页面集成接缝测试：拖动期间临时项目同时反映到时间轴和预览画布；松开后项目快照、自动保存和历史只发生一次最终提交；播放头移动会同步预览但不进入项目历史；粘贴后新片段被选中。
- 在快捷键行为测试：非输入焦点下 `Ctrl+C`、`Ctrl+V`、`Ctrl+Z`、`Ctrl+Y` 触发时间轴/项目行为；输入框、数字框、选择框和文本域内保留原生快捷键行为；无选中片段复制与无剪贴内容粘贴均为无操作。
- 继续复用现有时间轴测试、编辑器页面测试、编辑器存储测试和历史测试的夹具与断言风格，并为新增交互补充回归测试。
- 若浏览器级测试能够稳定模拟真实鼠标手势，应至少覆盖一次从按下、移动到松开的完整流程，验证不会在中间帧写入多条历史记录。

## Out of Scope

- 不实现关键帧编辑或参数随时间变化的关键帧动画。
- 不实现完整剪辑软件中的多视频轨道、磁性剪辑、波纹编辑、吸附到音频波形或复杂转场编辑。
- 不实现通过垂直拖动把特效片段手动移动到指定特效轨道。
- 不实现拖动到时间轴可视边缘时的自动横向滚动。
- 不实现 `Esc` 取消当前拖动手势。
- 不把播放头定位记录为项目编辑历史。
- 不在本功能中增加云端剪贴板、跨页面剪贴板或跨项目持久化剪贴板。
- 不改变现有本地工作区存储、导出格式或 Remotion 渲染协议。

## Further Notes

- 本规格补充并细化了既有时间轴交互反馈问题，尤其明确了拖动过程中的临时项目状态、一次性历史提交和播放头不入历史的边界。
- 规格依赖现有编辑项目、特效片段、视频片段、编辑器命令、编辑器历史和特效轨道布局概念，不引入新的领域术语。
- 当前工作区存在其他未提交改动，实现时必须保留这些改动，只修改与本规格直接相关的范围。
