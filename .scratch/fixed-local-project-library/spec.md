# 固定本地项目库与项目优先导航

Status: ready-for-agent

## Problem Statement

当前产品把“本地工作区”作为用户必须理解和切换的对象，但用户真正需要管理的是编辑项目。工作区路径、最近工作区、目录切换、空工作区和目录选择会把存储实现细节带入编辑流程；浏览器也无法安全地把用户选择目录的真实本地路径交给应用的本地服务。结果是用户和开发者都难以区分项目、素材和存储目录各自的责任。

## Solution

将产品收敛为固定的本地项目库和多个编辑项目。应用内部维护本地项目库目录，用户只管理编辑项目：新建、打开、重命名和删除。视频素材、个人预设、视频模板和导出结果都保存在本地项目库中，并继续遵循既有共享引用关系。

首次启动直接读取固定本地项目库；项目库为空时显示“新建编辑项目”状态。编辑页只显示当前编辑项目及项目管理入口，不显示工作区名称、路径、最近目录、目录选择或目录切换功能。

## User Stories

1. 作为使用者，我希望启动应用后直接看到编辑项目，而不需要理解或选择本地目录。
2. 作为首次使用者，我希望项目库为空时看到“新建编辑项目”，以便立即开始而不是先配置存储位置。
3. 作为使用者，我希望只通过项目名称区分和切换编辑内容，以便避免项目与目录混淆。
4. 作为使用者，我希望在编辑页清楚看到当前编辑项目名称，以便知道正在修改哪份内容。
5. 作为使用者，我希望通过项目选择器打开其他编辑项目，以便快速继续之前的工作。
6. 作为使用者，我希望在编辑页创建编辑项目，以便不离开当前创作流程。
7. 作为使用者，我希望新建编辑项目时填写名称，以便项目列表可辨识。
8. 作为使用者，我希望项目名称自动去除首尾空格，以便避免意外的重复项目。
9. 作为使用者，我希望项目名称不能包含路径字符或空名称，以便项目库保持安全稳定。
10. 作为使用者，我希望大小写不同的相同项目名称被拒绝，以便 Windows 环境下不会产生冲突。
11. 作为使用者，我希望重命名项目后继续编辑相同的内容和素材引用，以便名称调整不会破坏项目。
12. 作为使用者，我希望删除当前项目后自动打开最近编辑的其他项目，以便继续工作。
13. 作为使用者，我希望删除最后一个项目后回到空项目库状态，以便明确下一步是新建项目。
14. 作为使用者，我希望删除项目不删除视频素材，以便其他项目继续使用共享视频素材。
15. 作为使用者，我希望删除仍被项目引用的视频素材时被阻止，以便不会损坏项目。
16. 作为使用者，我希望个人预设和视频模板在项目库内可复用，以便在项目之间重复使用创作资产。
17. 作为使用者，我希望切换项目时只有未保存编辑存在才看到确认提示，以便减少不必要的打断。
18. 作为使用者，我希望取消切换后仍留在当前项目，以便不会丢失上下文。
19. 作为使用者，我希望自动保存失败或项目损坏时看到重试和从最近备份恢复，以便恢复已有成果。
20. 作为使用者，我希望应用中没有“选择工作区”“最近工作区”“打开目录”或目录路径输入，以便界面只表达项目操作。
21. 作为使用者，我希望旧项目数据能在升级后继续打开，以便固定项目库迁移不丢失成果。
22. 作为使用者，我希望以后通过导入、导出或备份迁移数据，而不是通过切换项目库目录。

## Implementation Decisions

- 固定本地项目库是唯一的本地持久化位置，目录位置属于应用内部实现，不对用户显示或提供切换。
- 应用启动时初始化或恢复固定本地项目库；首次使用不显示目录选择页面。
- 编辑项目是唯一的用户可见组织层级，项目生命周期只包含新建、打开、重命名和删除；不提供复制项目。
- 视频素材、个人预设、视频模板和导出结果属于本地项目库，在项目之间保持现有共享关系。
- 项目名称经过 trim 和路径安全校验，并以不区分大小写的规则判断唯一性。
- 项目列表按最近更新时间排序；删除当前项目后打开排序首项，列表为空时显示空项目库状态。
- 保留自动保存、最近备份和缺失素材恢复能力；这些能力不再依赖工作区切换。
- 移除用户可见的工作区状态、最近工作区、工作区设置、目录路径输入、目录打开接口和目录切换确认。
- 旧目录型数据在首次访问时迁移或兼容读取到固定本地项目库；迁移失败必须展示恢复错误，不得静默创建空项目。
- 未来数据迁移通过显式导入、导出和备份功能实现，不重新引入项目库目录选择。

## Testing Decisions

- 测试验证用户只能管理编辑项目，不能看到或触发项目库目录选择和切换。
- `App` 是用户状态的最高 seam，覆盖首次启动、空项目库、新建项目、项目切换、删除后导航、未保存确认和恢复提示。
- `WorkspaceAdapter` 保留为内部持久化 seam，覆盖固定项目库初始化、项目名称规则、项目恢复、共享视频素材引用保护和旧数据迁移。
- Playwright 覆盖真实浏览器流程：直接进入项目列表或空项目库状态，且页面中不存在目录选择路径和工作区设置入口。
- 测试只观察用户可见行为和持久化结果，不绑定 UI 组件的内部实现。
- 实现按 TDD 执行：先编写失败测试，再以最小改动通过测试，最后运行全量测试、类型检查、生产构建和浏览器验收。

## Out of Scope

- 不提供用户选择、切换或浏览本地项目库目录。
- 不接入 Electron、Tauri 或浏览器目录选择 API。
- 不实现云端同步、账号空间或多项目库。
- 不实现项目复制。
- 不改变视频片段时间基、共享视频素材引用模型、个人预设模型或视频模板模型。
- 不在本次变更中实现完整的数据导入、导出或备份中心。

## Further Notes

- 本规格遵守 ADR-0025：固定本地项目库取代用户可切换目录。
- “本地项目库”是内部持久化集合；“编辑项目”是用户进行创作和管理的工作对象。
- 旧的工作区导航规格已被本规格替代。
