# 03 — 项目优先编辑页与工作区功能收缩

**What to build:** 编辑页只让用户选择和管理编辑项目，移除所有用户可见的本地工作区、目录路径和目录切换功能。

**Blocked by:** 01 — 固定项目库初始化与旧数据兼容; 02 — 项目库启动与空项目库体验

**Status:** wontfix

- [ ] 顶栏直接显示当前编辑项目名称和项目选择器，项目管理仅提供新建、打开、重命名和删除。
- [ ] 不提供复制编辑项目、工作区设置、最近工作区、当前目录名称、目录路径输入或打开目录入口。
- [ ] 重命名项目保留项目内容和视频素材引用；删除当前项目后自动打开最近编辑的其他项目。
- [ ] 仅在自动保存进行中或失败时，项目切换前显示继续切换或返回编辑的确认。
- [ ] 覆盖项目选择、取消切换、重命名、删除后导航以及页面中不存在目录操作入口的组件测试。
