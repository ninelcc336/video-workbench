# 02 — 项目库启动与空项目库体验

**What to build:** 用户启动应用后直接进入编辑项目列表；本地项目库没有编辑项目时显示空项目库状态，并能创建第一个命名编辑项目。

**Blocked by:** 01 — 固定项目库初始化与旧数据兼容

**Status:** ready-for-agent

- [ ] 启动后直接加载固定本地项目库中的编辑项目，不展示本地目录或最近目录。
- [ ] 项目库为空时显示“空项目库状态”和“新建编辑项目”入口。
- [ ] 创建项目必须填写名称，名称自动 trim、拒绝路径字符和空名称，并按不区分大小写规则避免冲突。
- [ ] 项目列表按最近更新时间排序；删除最后一个编辑项目后回到空项目库状态。
- [ ] 覆盖启动、空项目库、新建项目、命名冲突和删除后状态的组件与浏览器验收测试。
