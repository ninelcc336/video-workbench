# 01 — 固定项目库初始化与旧数据兼容

**What to build:** 应用在无需用户选择目录的情况下启动固定本地项目库，并能安全读取或迁移既有目录型数据，让已有编辑项目、视频素材、个人预设和视频模板继续可用。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 应用启动时自动初始化或恢复固定本地项目库，不显示目录路径输入或目录选择要求。
- [ ] 固定本地项目库继续保存编辑项目、视频素材、个人预设、视频模板和导出结果。
- [ ] 既有目录型数据可以兼容读取或迁移到固定本地项目库，迁移不改变编辑项目与视频素材引用关系。
- [ ] 迁移或读取失败时显示可恢复错误，不静默创建空编辑项目。
- [ ] 覆盖固定项目库初始化、旧数据兼容和失败恢复的持久化测试。
