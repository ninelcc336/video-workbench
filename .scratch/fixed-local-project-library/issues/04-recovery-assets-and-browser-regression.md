# 04 — 恢复、共享资产与浏览器回归

**What to build:** 在固定本地项目库模型下验证自动保存、最近备份、缺失素材和共享视频素材引用保护仍然可恢复，并完成真实浏览器流程验收。

**Blocked by:** 01 — 固定项目库初始化与旧数据兼容; 02 — 项目库启动与空项目库体验; 03 — 项目优先编辑页与工作区功能收缩

**Status:** wontfix

- [ ] 自动保存失败和项目损坏时提供重试及从最近备份恢复入口，不替换当前编辑项目为伪造空项目。
- [ ] 缺失视频素材仍可重新关联，重新关联后保持编辑项目时间轴和特效布局。
- [ ] 选择不同视频重新关联时显示二次确认，并明确提示内容变化、时长不匹配，以及新素材不足以覆盖既有视频片段的风险；不得静默产生错误结果。
- [ ] 重新关联支持撤销，且不改变项目画布或特效布局。
- [ ] 删除编辑项目不删除视频素材；删除仍被任何编辑项目引用的视频素材仍被阻止。
- [ ] 素材详情展示文件名、格式、大小、时长和分辨率；重命名仅更新展示名称，不改变稳定素材引用。
- [ ] Playwright 覆盖项目库启动、空项目库、新建和切换项目、恢复入口、缺失素材重新关联/撤销和跨项目引用保护，以及页面不存在目录选择和工作区切换。
- [ ] 运行全量测试、类型检查、生产构建和浏览器验收。
