# 04 — 缺失素材重新关联与素材管理

**What to build:** 让用户能够识别、修复和管理本地工作区中的视频素材引用，而不会误删仍被项目使用的素材。

**Blocked by:** 03 — 视频素材元数据与片段导入

**Status:** wontfix

- [ ] 打开引用缺失视频素材的编辑项目时，项目仍可打开并明确标记缺失的视频片段。
- [ ] 用户可以选择本地文件重新关联缺失素材，并恢复预览和导出能力。
- [ ] 选择不同文件替换时显示二次确认、内容变化和时长不匹配风险。
- [ ] 替换后的素材时长不足以覆盖已有视频片段时，显示明确处理提示，不静默产生错误结果。
- [ ] 重新关联操作支持撤销，并且不改变项目画布或特效布局。
- [ ] 素材详情展示文件名、格式、大小、时长和分辨率；重命名不改变稳定素材引用。
- [ ] 删除素材前检查所有编辑项目引用；被引用素材不能直接删除，未被引用素材可以安全移除。
- [ ] 覆盖缺失检测、重新关联、撤销、跨项目引用保护和素材删除的端到端测试。
