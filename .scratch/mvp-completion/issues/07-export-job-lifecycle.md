# 07 — 导出任务闭环

**What to build:** 让用户能够可靠地发起、观察、取消、重试和定位 MP4 导出任务。

**Blocked by:** 03 — 视频素材元数据与片段导入；fixed-local-project-library/04 — 恢复、共享资产与浏览器回归

**Status:** resolved

- [x] 存在缺失素材或非法项目状态时，导出按钮被阻止并说明修复原因。
- [x] 导出任务展示准备中、渲染中、已完成、失败和已取消状态。
- [x] 准备中或渲染中可以取消任务，取消后不把半成品当作有效导出结果。
- [x] 失败任务显示阶段和错误摘要，并支持重新发起导出。
- [x] 多次导出使用不冲突的输出文件名，不无提示覆盖旧结果。
- [x] 导出完成后显示文件名、大小、生成时间和打开结果文件的入口。
- [x] 渲染任务继续消费项目快照，并保持预览和导出的模板定义一致。
- [x] 覆盖取消、失败重试、缺失素材阻止导出、结果文件管理和状态转换的服务端及浏览器测试。

## Comments

- 2026-07-23：按 ADR-0025 将已废弃的旧“工作区素材管理”依赖替换为固定本地项目库下的恢复与共享资产验收；用户视角仅管理编辑项目。
- 2026-07-23：验收反馈：导出任务闭环基本无问题，全部验收项通过。
