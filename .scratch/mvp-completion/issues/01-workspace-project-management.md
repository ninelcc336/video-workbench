# 01 — 工作区与编辑项目管理

**What to build:** 让用户能够在界面中选择或切换本地工作区，并在工作区内管理多个命名的编辑项目。

**Blocked by:** None — can start immediately

**Status:** wontfix

- [ ] 首次使用时可以选择或创建本地工作区，并记住最近使用的工作区。
- [ ] 切换工作区后重新加载该工作区的编辑项目和资产列表。
- [ ] 可以创建、列出、打开、重命名、复制和删除编辑项目。
- [ ] 删除项目时只删除项目记录，不级联删除其他项目可能引用的视频素材。
- [ ] 切换工作区或项目时，对未保存编辑显示明确提示。
- [ ] 工作区和项目操作失败时显示可理解的错误，不静默回退到空编辑项目。
- [ ] 为工作区切换和项目生命周期提供领域、服务端和浏览器端行为测试。

## Comments

- 2026-07-22：已被固定本地项目库规格替代。编辑项目 CRUD、共享素材保护和错误恢复已实现；用户可见的工作区选择、切换和项目复制按 ADR-0025 不再提供。
