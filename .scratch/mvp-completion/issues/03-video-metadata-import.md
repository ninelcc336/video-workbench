# 03 — 视频素材元数据与片段导入

**What to build:** 让用户导入真实可用的视频素材，并让新建的视频片段使用正确的元数据和完整时长。

**Blocked by:** fixed-local-project-library/01 — 固定项目库初始化与旧数据兼容

**Status:** resolved

- [x] 导入阶段拒绝非视频文件、损坏文件和无法读取元数据的文件。
- [x] 新建视频片段默认使用源视频完整时长，并追加到主视频轨道末尾。
- [x] 空编辑项目导入首个视频素材时，根据素材比例设置画布，根据素材帧率设置项目帧率。
- [x] 无法读取帧率时回退到 30fps，并向用户说明使用了回退值。
- [x] 后续视频素材不自动改变已有编辑项目的画布和帧率。
- [x] 大文件导入显示处理中状态，导入失败不留下不可用的本地项目库素材。
- [x] 覆盖元数据读取、完整时长、首个视频规格匹配和异常导入的领域、服务端及浏览器测试。

## Out of Scope

- 素材库展示大小、分辨率和帧率不纳入当前阶段的验收范围。

## Comments

- 2026-07-23：按 ADR-0025 更新依赖与术语。用户不再选择或切换工作区；视频素材属于应用内部维护的固定本地项目库，并通过编辑项目使用。
- 2026-07-23：验收反馈：素材库展示大小、分辨率和帧率不纳入当前阶段；其余验收项已验证通过，本 issue 已完成。
