# 08 — MVP 端到端验收

**What to build:** 用真实视频走通本地优先编辑器的完整创作闭环，并确认预览和 MP4 导出结果一致。

**Blocked by:** fixed-local-project-library/04 — 恢复、共享资产与浏览器回归；07 — 导出任务闭环

**Status:** resolved

- [x] 用户启动后直接进入固定本地项目库，创建编辑项目并导入真实视频素材；界面不暴露工作区选择或切换。
- [x] 用户可以排列视频片段，添加 2–3 个特效，修改特效参数并查看过程预览。
- [x] 用户可以关闭并重新打开应用，恢复项目、素材、特效、预设和视频模板。
- [x] 模拟素材缺失后，用户可以重新关联素材并恢复导出。
- [x] 用户可以完成一次导出、观察状态、定位 MP4 结果文件。
- [x] 覆盖竖屏、横屏和方形项目，以及首个视频不同帧率的场景。
- [x] 至少验证信息叠加、装饰动画和片段转场模板的预览/导出关键画面一致。
- [x] 现有单元测试、类型检查、生产构建和浏览器端验收全部通过。

## Out of Scope

- 个人预设和视频模板的保存、重新打开后的套用，改由后续独立安排验收，不再纳入本 issue。

## Comments

- 2026-07-23：按 ADR-0025 更新端到端入口与依赖。验收以固定本地项目库和编辑项目为用户可见边界，不再验证工作区选择或切换。
- 2026-07-23：验收反馈：除个人预设和视频模板外，其余验收项已验证通过；预设与模板能力已移出本 issue，按后续独立安排处理。
