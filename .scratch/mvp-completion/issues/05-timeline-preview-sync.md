# 05 — 时间轴与预览完整联动

**What to build:** 让时间轴成为可靠的编辑入口，所有定位和片段操作都即时反映到预览、选区和参数面板。

**Blocked by:** None — can start immediately

**Status:** resolved

- [ ] 点击时间轴标尺或空白区域可以定位播放头，播放头、预览和时间显示保持同步。
- [ ] 点击视频片段或特效片段后，选中状态、预览选区和参数面板保持同步。
- [ ] 拖动片段可以改变起始帧，拖动边缘可以调整持续时间。
- [ ] 片段操作不会产生负帧或零时长片段。
- [ ] 从模板库拖到时间轴指定位置可以创建特效片段。
- [ ] 删除选中片段后时间轴、预览和参数面板立即同步。
- [ ] 拖动过程使用临时预览，松开后只提交一次正式编辑历史。
- [ ] 时间轴定位、移动、裁剪、拖放、删除和撤销重做提供组件及端到端回归测试。

## Comments

- 2026-07-22：已完成播放头、预览、选区与参数面板同步，以及时间轴定位、移动、裁剪、拖放、删除、过程预览和撤销重做。细粒度时间轴手势由组件与领域测试覆盖；浏览器验收覆盖编辑器主流程和画布布局回归。
