# 06 — 个人预设与视频模板持久化

**What to build:** 让个人预设和视频模板成为可跨会话复用的本地工作区资产。

**Blocked by:** 01 — 工作区与编辑项目管理

**Status:** resolved

- [ ] 个人预设可以保存到工作区，并支持列表展示、套用和删除。
- [ ] 个人预设只保存特效模板引用和参数，不复制模板实现或视频素材。
- [ ] 视频模板可以保存到工作区，并支持列表展示、套用和删除。
- [ ] 视频模板只保存特效片段的相对时间轴布局，不保存视频素材。
- [ ] 套用视频模板时新增特效片段，不覆盖当前项目。
- [ ] 一次模板套用只产生一条撤销历史和一次自动保存，并自动避让已有特效轨道。
- [ ] 模板套用到不同帧率项目时保持原来的秒数位置和持续时间。
- [ ] 模板版本不兼容时提示用户并使用安全的默认参数兜底。
- [ ] 覆盖保存、重新打开、列表、套用、删除、原子撤销和跨帧率换算的测试。

## Comments

- 2026-07-22：已完成个人预设与视频模板的本地持久化、列表、套用和删除；模板仅保存特效布局，跨帧率换算、自动轨道避让及一次撤销已由领域、仓储与组件测试覆盖。
