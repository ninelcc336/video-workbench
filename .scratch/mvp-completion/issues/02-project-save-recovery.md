# 02 — 项目可靠保存与恢复

**What to build:** 让编辑项目在自动保存、应用重启、项目文件损坏或数据版本升级后仍可安全恢复。

**Blocked by:** 01 — 工作区与编辑项目管理

**Status:** resolved

- [ ] 编辑操作经过防抖后自动保存，并展示已保存、保存中和保存失败状态。
- [ ] 保存失败时保留内存中的编辑结果，并提供重试入口。
- [ ] 保存项目时保留一个最近版本备份，正式文件使用安全替换方式写入。
- [ ] 项目数据版本升级时自动迁移旧项目，迁移失败不得覆盖原文件。
- [ ] 正式项目文件损坏时可以从最近备份恢复。
- [ ] 项目读取异常时展示错误、重试和恢复选项，不创建空编辑项目覆盖用户认知。
- [ ] 覆盖自动保存、备份恢复、迁移失败和读取失败保护的回归测试。
