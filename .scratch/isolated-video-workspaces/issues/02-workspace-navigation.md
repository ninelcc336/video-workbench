# 02 — 视频工作区创建与切换

**What to build:** 用户通过视频工作区管理 A、B 等独立创作内容，而不接触编辑项目或底层目录。

**Blocked by:** 01 — 视频工作区模型与旧数据迁移

**Status:** resolved

- [x] 空工作区库状态提供“新建视频工作区”入口。
- [x] 用户可以创建、打开、切换、重命名和删除视频工作区；名称 trim、路径安全且不区分大小写唯一。
- [x] 顶栏显示当前视频工作区名称，不出现编辑项目、本地项目库或目录路径。
- [x] 自动保存进行中或失败时，切换工作区前提示确认；已保存时直接切换。
- [x] 删除当前工作区后打开最近编辑的其他工作区；删除最后一个后回到空工作区库状态。
- [x] 覆盖工作区生命周期、切换确认和页面术语的组件及浏览器测试。
