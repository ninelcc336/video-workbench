# 01 — 视频工作区模型与旧数据迁移

**What to build:** 用视频工作区取代编辑项目与共享项目库，并安全迁移已有数据。

**Blocked by:** None — can start immediately

**Status:** resolved

- [x] 领域模型、持久化类型和服务端接口以视频工作区为边界，不再暴露编辑项目概念。
- [x] 每个工作区独立保存工作区快照、素材和导出结果；素材 ID 不跨工作区引用。
- [x] 既有编辑项目可迁移为视频工作区；被多个旧编辑项目引用的素材复制到每个对应工作区。
- [x] 迁移失败时保留原始数据并提供可恢复错误，不创建伪造空工作区。
- [x] 覆盖单工作区迁移、多引用素材复制、迁移失败和数据恢复的持久化测试。
