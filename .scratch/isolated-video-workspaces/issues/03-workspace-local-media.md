# 03 — 工作区本地素材管理

**What to build:** 让每个视频工作区只管理自身导入的素材，彻底移除跨工作区素材共享。

**Blocked by:** 01 — 视频工作区模型与旧数据迁移; 02 — 视频工作区创建与切换

**Status:** resolved

- [x] 在工作区 B 导入的素材不出现在工作区 A 的素材库或时间轴中。
- [x] 素材重命名、重新关联、撤销重新关联和删除只影响当前工作区。
- [x] 删除素材不再扫描其他工作区引用；当前工作区仍引用的素材必须受保护。
- [x] 缺失素材保持为当前工作区可恢复状态，修复后不改变该工作区时间轴、特效和设置。
- [x] 覆盖素材隔离、工作区内引用保护、缺失恢复和迁移后素材复制的服务端与浏览器测试。
