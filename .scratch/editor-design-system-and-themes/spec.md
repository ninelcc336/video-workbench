# 编辑器设计系统与主题规格

Status: ready-for-agent

## Problem Statement

模板化特效编辑器的主编辑区已有深色工作台基础，但用户在完成一次视频工作区创作时，会在定制化的三栏编辑器、未样式化的导出与资产弹窗、浏览器原生提示框和默认表单控件之间频繁切换。控件层级、图标语义、焦点状态和危险操作提示不一致，影响专业感，也让新用户难以在十分钟内有把握地完成导入视频素材、添加特效片段、保存个人预设或视频模板并导出 MP4。

同时，界面目前没有一目了然的深浅主题入口。用户需要通过带文字的下拉控件理解并修改主题，无法用紧凑图标快速判断当前主题和下一次切换的结果。

## Solution

将编辑器升级为一套面向专业桌面视频工作台的统一设计系统。设计系统以语义化令牌提供深色与浅色外观；首次使用默认深色并显示月亮图标，点击后切换浅色并显示太阳图标，用户选择保存为本地偏好。

应用内的按钮、表单、菜单、对话框、提示反馈和图标统一使用自定义、可访问的界面组件；文件与目录选择继续交由系统选择器。实施分两批：先消除导出、个人预设、视频模板、视频素材管理和通知中的原生 UI，再统一模板库、特效参数面板、过程预览和时间轴。桌面端以 1280×800 为主要验收尺寸，1024×768 为完整可用下限，并以轻量微动效反馈操作、尊重“减少动态效果”偏好。

## User Stories

1. 作为视频创作者，我希望整个视频工作区编辑流程采用一致的视觉语言，以便专注创作而不是辨认不同来源的控件。
2. 作为首次使用者，我希望初次打开编辑器时自动跟随操作系统的明暗外观，以便无需先配置界面。
3. 作为视频创作者，我希望通过月亮或太阳图标一键切换深浅主题，以便不用阅读主题下拉选项也能立即理解当前状态。
4. 作为已选择深色或浅色主题的创作者，我希望再次打开应用时保留我的选择，以便不必重复设置。
5. 作为视频创作者，我希望深色主题默认显示月亮、浅色主题显示太阳，以便按钮本身成为当前主题的视觉提示。
6. 作为视频创作者，我希望点击主题图标只在深色和浅色之间切换，以便切换结果始终可预测。
7. 作为使用键盘的创作者，我希望主题选择器有明确名称、当前状态和可见焦点，以便无需鼠标完成切换。
8. 作为对动态敏感的创作者，我希望系统启用“减少动态效果”后界面停止非必要过渡，以便舒适地编辑视频。
9. 作为在强光环境工作的创作者，我希望浅色主题仍清晰区分画布、面板、时间轴、选中项和错误状态，以便不牺牲编辑效率。
10. 作为在暗光环境工作的创作者，我希望深色主题保持专业工作台的层级和对比度，以便长时间编辑时更舒适。
11. 作为视频创作者，我希望顶栏中的撤销、重做、重置、主题和导出操作使用一致的 SVG 图标与文字提示，以便快速理解其用途。
12. 作为视频创作者，我希望主操作、次要操作、危险操作和禁用操作有稳定且可辨认的样式，以便在导出、删除或重置时做出正确判断。
13. 作为视频创作者，我希望导出设置显示为完整、可聚焦且视觉一致的对话框，以便放心选择输出规格并开始导出。
14. 作为视频创作者，我希望在导出进行、完成、失败或取消时看到统一的状态反馈和可用操作，以便知道下一步应该重试、取消、查看结果或关闭提示。
15. 作为视频创作者，我希望保存个人预设时使用与其他表单一致的对话框，以便清楚地命名、保存、套用和删除个人预设。
16. 作为视频创作者，我希望保存、套用或删除视频模板时获得一致的确认与反馈，以便复用特效片段布局而不担心误操作。
17. 作为视频创作者，我希望重命名或移除视频素材不再触发浏览器原生提示框，以便这些操作与编辑器其余流程保持一致且可访问。
18. 作为视频创作者，我希望删除、重置和其他不可逆操作有清楚的危险层级与确认文案，以便避免误伤视频工作区、视频素材、个人预设或视频模板。
19. 作为视频创作者，我希望模板库保留并强化已有的动效预览，以便继续通过“看到效果再选择”来发现特效模板。
20. 作为视频创作者，我希望特效参数面板的文字、数字、颜色、开关与选择控件具有统一样式和错误/焦点反馈，以便精确调整特效参数。
21. 作为视频创作者，我希望过程预览中的选区、拖拽手柄和时间轴选中片段在两套主题下都足够清晰，以便可靠地移动、缩放和选择特效片段。
22. 作为笔记本电脑用户，我希望在 1280×800 的窗口中同时看见素材与模板、过程预览、特效参数和时间轴，以便维持现有三栏工作流。
23. 作为使用较小桌面窗口的创作者，我希望在 1024×768 的窗口中仍能使用全部编辑功能，而不出现遮挡、不可达的操作或页面级溢出，以便不必更换设备才能编辑。
24. 作为键盘和辅助技术用户，我希望菜单和对话框具有正确的焦点管理、Esc 关闭、可访问名称和状态播报，以便独立完成导出与资产管理。
25. 作为视频创作者，我希望更换界面主题或视觉组件不会改变视频片段、特效片段、个人预设、视频模板、自动保存或 MP4 导出的结果，以便界面升级不会影响已有创作。
26. 作为维护者，我希望新增界面功能可复用统一组件和主题令牌，以便后续迭代不会重新引入原生 UI 或局部配色漂移。

## Implementation Decisions

- 以 ADR-0027 为准：编辑器采用专业桌面视频工作台视觉语言；它补充 ADR-0018 的三栏布局，不能替换或缩减左侧模板发现、中间过程预览、右侧特效参数和底部时间轴。
- 建立应用级主题控制器，唯一负责主题偏好读取、默认值、持久化和向页面根节点暴露当前主题。主题偏好取值为 `dark`、`light`；默认 `dark`。
- 用户点击图标在深色与浅色之间切换，并持久化到当前浏览器本地。存储不可用、非法或旧版主题值时安全回退到 `dark`。
- 使用语义化设计令牌描述背景、层级表面、边框、正文/辅助/反色文字、主色、危险色、状态色、焦点环、阴影、圆角、间距、字号和动效时长。业务组件不得直接把主题颜色编码为单独的视觉决策。
- 在保留现有 React 与 Radix 可访问能力的基础上，建立按钮、图标按钮、表单字段、选择器、菜单、对话框、确认对话框、通知和状态卡片等基础组件。允许引入统一 SVG 图标库替代 Unicode 工具图标；图标按钮必须提供可访问名称或可见文字。
- 所有应用内确认、命名、选择、导出和状态反馈使用统一组件。浏览器原生 `prompt`、默认未样式化对话框、默认选择控件和无样式危险操作不得作为产品 UI 暴露；操作系统文件/目录选择器仍保留。
- 主题选择入口属于应用级控制区，并在启动状态和视频工作区编辑状态中可访问；它不显示“界面主题”文字，而以月亮/太阳图标和可访问操作说明表达切换；切换不触发工作区保存、编辑命令、时间轴重算或预览帧变化。
- 首批迁移覆盖导出流程、个人预设、视频模板、视频素材管理、工作区管理与应用通知；第二批迁移模板库、特效参数面板、过程预览控制、选区交互、时间轴及其状态。
- 模板库继续以已有短动效预览为主要发现方式，模板名称和描述仅作辅助；视觉升级不得改为静态缩略图或移除拖拽到时间轴、在播放头添加等现有入口。
- 动效仅用于菜单、对话框、通知、按钮和状态变化的轻量反馈；须在系统“减少动态效果”偏好下关闭或缩减。不得让装饰性动效妨碍过程预览、拖动选区或时间轴操作。
- 视觉验收主尺寸为 1280×800，1024×768 是可用下限。当前桌面优先范围不要求移动端重排为单栏；面板调整、局部滚动和现有三栏语义必须继续可用。
- 不改变视频工作区、视频素材、视频片段、特效片段、特效参数、个人预设、视频模板和导出任务的数据模型，也不改变前端对编辑器命令、工作区服务或渲染服务的契约。

## Testing Decisions

- 测试只验证用户可观察的主题、可访问性、操作结果和创作闭环，不绑定 CSS 类名、DOM 层级、具体图标实现或 Radix 内部结构。
- 以应用根层作为主题的最高测试 seam：验证默认深色、月亮/太阳图标切换、偏好持久化、非法或旧版持久化值回退，以及主题切换不改变当前视频工作区编辑快照。
- 使用既有页面与组件测试覆盖高频对话框和表单：导出规格提交、个人预设和视频模板的保存/套用/删除、视频素材重命名/移除、工作区管理、重置确认和导出任务状态。测试应通过用户可见名称、角色、键盘操作与回调结果验证行为。
- 以现有 Playwright 创作闭环为浏览器级 seam，覆盖在桌面尺寸下导入视频素材、添加特效片段、调整参数、保存个人预设、选择主题、导出并查看状态；主题切换前后必须保持同一编辑结果。
- 为深色和浅色主题在 1280×800 与 1024×768 建立代表性视觉验收场景：空工作区库、含视频素材与特效片段的编辑器、导出对话框、危险确认对话框和导出完成状态。视觉检查应关注无页面溢出、可读对比、焦点可见和关键操作不被遮挡。
- 新增行为先以失败测试描述，再实现；完成后运行组件测试、端到端测试、类型检查、生产构建和浏览器验收。

## Out of Scope

- 移动端、平板端或将桌面三栏编辑器重排为单栏的响应式重构。
- 用户自定义调色板、品牌皮肤、按视频工作区保存主题，或为单个特效模板提供独立主题。
- 跟随操作系统主题自动切换。
- 操作系统文件/目录选择器的外观定制。
- 更改视频工作区、视频素材、视频片段、特效片段、特效参数、个人预设、视频模板或导出任务的领域模型和持久化格式。
- 改变模板动效的渲染实现、视频过程预览与 MP4 导出一致性、时间轴交互语义或现有编辑命令。
- 新增 AI、云端同步、账号、桌面安装包、字幕、音频轨道或其他完整剪辑软件能力。

## Further Notes

- 本规格使用项目术语表定义的“视频工作区”“视频素材”“视频片段”“特效片段”“特效参数”“过程预览”“个人预设”“视频模板”和“导出任务”等词汇。
- 实施必须同时遵循 ADR-0012（模板库以动效预览为主）、ADR-0018（标准三栏布局）、ADR-0021（十分钟创作闭环）与 ADR-0027（统一设计系统与主题）。
- 当前代码已在应用根层集中协调视频工作区状态，且已有页面测试与 Playwright 创作闭环；主题系统应复用这个高层入口，不将主题逻辑散落到单个编辑组件。
- 主题偏好是本地 UI 偏好，不属于视频工作区内容；切换主题不应触发自动保存，也不应写入视频工作区文件。
