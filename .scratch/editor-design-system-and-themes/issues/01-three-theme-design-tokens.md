# 01 — 三种主题与全局设计令牌

**What to build:** 让视频创作者能在跟随系统、深色和浅色主题之间切换。首次使用跟随系统，手动选择会保存为本地偏好；整个编辑器在两套主题中保持一致、可读的专业桌面工作台外观，且主题切换不影响当前视频工作区的编辑状态。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 首次使用默认跟随系统；手动选择深色或浅色后刷新应用仍保留选择，切回跟随系统后会响应系统主题变化。
- [ ] 视频工作区启动状态与编辑状态均可访问主题选择，并具备键盘操作、可见焦点和正确的可访问名称。
- [ ] 编辑器的背景、面板、文字、边框、状态、焦点和主要操作在深色与浅色主题下均由统一语义令牌呈现，切换不触发保存或改变视频片段、特效片段和过程预览帧。
- [ ] 系统启用“减少动态效果”时，主题与界面过渡不会产生非必要动画。
