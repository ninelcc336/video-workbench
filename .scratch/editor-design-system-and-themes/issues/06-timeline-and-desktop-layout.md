# 06 — 时间轴与桌面尺寸适配升级

**What to build:** 让视频创作者在统一主题下清楚辨认时间轴、视频片段、特效片段、播放头和调整手柄，并在 1280×800 与 1024×768 的桌面窗口中维持可操作的三栏编辑工作流。

**Blocked by:** 01 — 三种主题与全局设计令牌。

**Status:** ready-for-agent

- [ ] 时间轴的标尺、轨道、视频片段、特效片段、选中状态、播放头和调整手柄在深色与浅色主题下具有一致且可辨认的层级。
- [ ] 拖动、缩放、选择、删除和播放头定位保持既有时间轴语义，并获得克制的交互反馈。
- [ ] 在 1280×800 与 1024×768 下，素材与模板、过程预览、特效参数和时间轴均可访问，无页面级溢出或关键操作遮挡。
- [ ] 时间轴交互和面板调整的页面级测试继续通过，并增加目标桌面尺寸的浏览器验收。
