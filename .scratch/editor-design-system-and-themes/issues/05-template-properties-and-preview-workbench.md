# 05 — 模板库、特效参数与过程预览升级

**What to build:** 让视频创作者在两套主题下使用一致、清晰的左侧模板发现、右侧特效参数和中央过程预览；保留特效模板的短动效预览、拖入时间轴和播放头添加，以及画布选区的直接调整。

**Blocked by:** 01 — 三种主题与全局设计令牌。

**Status:** ready-for-agent

- [ ] 模板库保留以动效预览为主的发现方式，并在悬停、拖拽、分类切换和添加操作中提供一致的视觉反馈。
- [ ] 特效参数的文字、数字、颜色、开关和选择控件在深色与浅色主题下清晰可读，焦点、禁用和错误状态明确。
- [ ] 过程预览控制、特效选区和拖拽手柄在两套主题下均保持足够对比度，且不改变特效片段的调整语义。
- [ ] 模板添加、特效参数修改、过程预览选择与画布直接调整的现有行为通过页面级测试继续验证。
