# 07 — 双主题创作闭环验收

**What to build:** 让视频创作者在深色与浅色主题、两种目标桌面尺寸下，均能可靠完成导入视频素材、添加特效片段、调整特效参数、保存个人预设和导出 MP4 的完整闭环；修正跨模块出现的视觉、可访问性或状态一致性问题。

**Blocked by:** 02 — 统一导出对话框与导出任务反馈；03 — 个人预设与视频模板资产流程升级；04 — 视频工作区与视频素材管理流程升级；05 — 模板库、特效参数与过程预览升级；06 — 时间轴与桌面尺寸适配升级。

**Status:** ready-for-agent

- [ ] 在深色和浅色主题中，完整创作闭环保持相同的视频工作区、视频片段、特效片段、个人预设和导出结果。
- [ ] 空视频工作区、编辑器、导出对话框、危险确认和导出完成状态在 1280×800 与 1024×768 下均无关键操作遮挡、页面级溢出或不可读状态。
- [ ] 主题切换、键盘焦点、对话框焦点管理和“减少动态效果”偏好在浏览器级验收中可用。
- [ ] 组件测试、端到端测试、类型检查和生产构建全部通过。
