# 02 — 统一导出对话框与导出任务反馈

**What to build:** 让视频创作者在统一、可访问的界面中选择导出规格、开始导出，并清晰处理准备中、渲染中、完成、失败和取消状态；导出任务仍按现有规则生成 MP4，不改变视频工作区内容。

**Blocked by:** 01 — 三种主题与全局设计令牌。

**Status:** ready-for-agent

- [ ] 导出规格通过自定义对话框选择，支持键盘焦点、Esc 关闭和明确的取消、开始导出操作。
- [ ] 导出任务的各状态在深色与浅色主题下均有一致的状态层级、可访问播报和对应操作。
- [ ] 完成状态保留查看导出结果与关闭提示的现有能力；失败与可取消状态仍可重试或取消。
- [ ] 导出规格提交、渲染状态转换及其用户可见行为通过组件和浏览器级测试覆盖。
