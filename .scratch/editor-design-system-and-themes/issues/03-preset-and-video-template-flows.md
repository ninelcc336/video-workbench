# 03 — 个人预设与视频模板资产流程升级

**What to build:** 让视频创作者以统一的应用内对话框保存、套用和删除个人预设与视频模板，明确每项资产对当前特效片段或时间轴布局的影响，并在两套主题下得到一致的确认和反馈。

**Blocked by:** 01 — 三种主题与全局设计令牌。

**Status:** ready-for-agent

- [ ] 保存个人预设和视频模板时可命名、取消和确认，表单校验与禁用状态清晰可见。
- [ ] 套用个人预设或视频模板保持现有特效参数与时间轴布局语义，并向用户给出明确反馈。
- [ ] 删除个人预设或视频模板具有明确危险层级与确认，不再依赖浏览器原生界面。
- [ ] 个人预设和视频模板的保存、套用、删除及键盘可访问行为通过页面级测试覆盖。
