# 特效库扩展与深度自定义规格

Status: ready-for-agent

## Problem Statement

模板化特效编辑器目前只有 7 个内置特效模板：5 个信息叠加、1 个装饰动画和 1 个名义上的片段转场。模板参数虽然由声明自动生成控件，但只有文字、颜色、数字、选择、开关、位置和尺寸七种基础类型，且所有参数平铺展示。清单和标签依赖特殊分隔符输入，动画普遍共用固定缓动和单一入场/出场时长，字体、渐变、描边、阴影、结构化内容、持续动画、随机种子和画幅默认布局等能力缺失。

现有模板以独立 TSX 文件重复声明默认值、参数和动画逻辑。继续按这个方式增加数量会放大重复实现、参数语义漂移、横竖画幅失控和预览/导出不一致风险。当前 `BasicTransition` 也只是在视频上方渲染纯色覆盖层，无法读取相邻视频片段，不满足领域术语中“片段转场”的含义。

## Goals

1. 建立统一特效开发基座，使编辑器、模板库和 Remotion 渲染器只依赖稳定的特效族声明接口。
2. 将特效参数按内容、布局、外观、动画和行为组织，并提供基础参数与高级特效参数的渐进式编辑体验。
3. 首个扩展里程碑交付 15 个特效族、至少 40 个达到质量门槛的起始样式。
4. 优先服务知识口播、产品讲解和教程类知识讲解视频。
5. 将片段转场升级为绑定相邻视频片段、同时合成前后画面的真实视觉过渡。
6. 在首次正式发布前直接收敛到新的特效族、参数和持久化模型，不承担开发期旧特效兼容成本。
7. 让 16:9 与 9:16 成为一等画幅，1:1 保持基本可用。
8. 让新增特效从复制模板文件转变为复用渲染原语、声明参数和设计起始样式。

## Solution

以“特效族 + 起始样式”替代“一种外观一个独立模板”的扩展方式。特效族封装共同的表达目的、参数语义和时间行为；起始样式只提供经过设计的默认参数。特效开发基座在统一接口内部处理参数归一化、画幅默认值、样式切换、三段式动画、确定性随机和渲染安全。

编辑器属性面板根据新版参数声明生成分组控件。基础模式优先展示每个特效最重要的 5–8 个参数并维持安全布局；高级模式允许更广的表现范围，对越界、低对比、过长内容和高渲染负载给出警告，只对无效数据或不可渲染状态进行硬限制。

模板库继续以短动效预览为主要发现方式，在现有三种顶层特效类型下增加特效用途标签、名称搜索、最近使用和个人预设入口。预览只在卡片可见或悬停时播放。

交付先完成特效开发基座和三个试点特效族：清单与步骤、手绘重点标注、方向推拉与擦除。试点通过完整质量门槛后，再用新模型重建现有特效的对应特效族并扩展其余目录。

## User Stories

1. 作为知识讲解视频创作者，我希望通过用途标签和动效预览快速找到适合标题、步骤、数字、对比或重点标注的特效。
2. 作为新用户，我希望添加特效后只调整少量基础参数就能得到可靠结果。
3. 作为高级用户，我希望展开高级特效参数，调整字体、渐变、描边、阴影、布局、动画阶段和行为。
4. 作为创作者，我希望逐项编辑、增删和排序清单、标签、步骤或对比项，而不是学习特殊分隔符。
5. 作为创作者，我希望分别调整入场、持续和出场阶段的时长、方向、缓动、强度和交错方式。
6. 作为创作者，我希望装饰动画在相同随机种子下保持稳定，以便预览和导出结果一致。
7. 作为创作者，我希望切换起始样式时保留文字、数字、列表和特效片段时间范围。
8. 作为创作者，我希望默认保留自己调整的位置与尺寸，只替换视觉和动画表现。
9. 作为创作者，我希望把品牌外观保存为样式预设，套用时不覆盖当前内容。
10. 作为创作者，我希望按需保存包含固定文案或人物信息的完整预设。
11. 作为横屏和竖屏视频创作者，我希望同一个特效根据画幅选择合理布局，不必寻找单独的横屏版或竖屏版。
12. 作为高级用户，我希望有意把元素移出安全区域或进行裁切，同时收到明确而不打断操作的警告。
13. 作为视频编辑者，我希望片段转场真实连接前后视频画面，而不是只覆盖一个纯色色块。
14. 作为视频编辑者，我希望移动或删除相邻视频片段时，绑定在交界点的片段转场不会悄悄落到错误位置。
15. 作为维护者，我希望新增起始样式主要是设计参数工作，不需要修改属性面板、模板库或渲染器调用方。
16. 作为维护者，我希望每个公开参数都由契约测试证明能够改变画面，并在横竖画幅和极端输入下保持可渲染。

## Effect Family Contract

特效开发基座是一个深模块。其外部接口负责以下能力，具体数据清洗、默认值合并和渲染辅助逻辑不得泄漏到编辑器调用方：

- 按 ID 和版本查找特效族，按类型、用途标签、视觉方向和文本查询目录。
- 基于特效族、起始样式和目标画幅创建完整特效片段参数。
- 归一化并验证参数，区分阻断错误和非阻断警告。
- 在同一特效族内切换起始样式，并按参数角色保留用户内容和默认布局。
- 为过程预览和 Remotion 导出生成完全一致、确定性的渲染输入。

每个特效族声明至少包含：稳定 ID、当前版本、顶层特效类型、名称、描述、用途标签、支持的视觉方向、默认持续时间、参数 schema、起始样式、画幅默认值以及渲染定义。起始样式使用族内稳定 ID，并可为 16:9、9:16 和 1:1 覆盖布局默认值。

特效片段保存所选特效族 ID、当前版本、起始样式 ID 和完整参数快照。首次正式发布前不读取缺少这些字段的开发期旧片段；开发数据应清空或重建。

## Parameter Model

参数声明必须包含所属参数分组、基础或高级层级、默认值、约束、说明和样式切换保留策略。参数分组固定为：

- 内容：文字、数字、结构化列表、图标和内容开关。
- 布局：位置、尺寸、锚点、旋转、对齐、内外边距和安全区域行为。
- 外观：字体、字号、字重、颜色、渐变、透明度、圆角、描边、阴影和模糊。
- 动画：入场、持续、出场、时长、延迟、方向、缓动、强度和交错。
- 行为：循环、密度、随机种子、响应画幅和特效族特有行为。

新版 schema 至少支持现有七种参数，以及多行文字、结构化列表、渐变、间距、字体、图标和动画阶段声明。属性面板应为数字范围优先提供滑杆与精确输入，为枚举提供菜单或分段控件，为颜色提供色板，为布尔值提供开关，为结构化列表提供可排序条目编辑器，为字体和图标提供可搜索选择器。

基础面板由每个特效族选择 5–8 个最高频参数。高级面板按参数分组折叠展示其余参数，并支持分组重置。基础模式对位置、尺寸、文字适配和安全边距执行保护；高级模式允许越界和裁切，对长文本、低对比、画面越界和高粒子密度产生非阻断警告。NaN、无限值、未知枚举、非法颜色、无效结构和超过渲染安全上限的值必须被阻止或回退到明确默认值。

结构化内容参数以数组保存条目，不使用换行、逗号或竖线作为持久化协议。编辑器可以将用户粘贴的多行文本转换成条目，但渲染器只消费结构化数据。每种列表声明字段 schema、最少和最多条目数、默认条目以及是否允许排序。

## Animation Model

动画统一采用入场、持续、出场三段式，不提供任意参数关键帧。每个特效族按需声明阶段：

- 入场和出场分别支持持续时间、延迟、方向、缓动、强度和逐项交错。
- 持续阶段可以静止，也可以按声明支持漂浮、脉冲、扫描、绘制或循环。
- 装饰动画可以声明循环、密度和随机种子；所有随机结果必须由项目数据和局部帧确定，不读取真实时间或调用无种子的随机数。
- 动画阶段总时长超过特效片段时，基座按稳定规则压缩阶段并产生非阻断警告，不允许负帧或跳变。
- 所有动画函数必须支持任意帧直接求值，保证暂停、跳转、过程预览和离线渲染一致。

## Built-in Asset Slots

首阶段只支持仓库内审核过的字体、图标和装饰素材。素材槽位引用稳定资源 ID，不保存绝对文件路径或远程 URL。所有内置资源必须包含来源、许可证和再分发说明，并在构建与 Remotion 渲染中冻结为本地文件。

本阶段不导入用户字体、Logo、图片或可执行模板代码。特效族元数据和起始样式应保持可序列化，为未来安全模板包保留空间，但不得为尚不存在的第三方适配器引入公开 seam。

## Starting Style And Preset Semantics

起始样式切换必须作为一次可撤销编辑命令执行。切换时：

- 始终保留内容参数和特效片段时间范围。
- 默认保留位置与尺寸；用户可以在确认预览中选择采用新样式的画幅布局。
- 外观、动画和行为参数替换为目标样式默认值。
- 新样式无法容纳原结构化内容时，先显示差异和警告，不静默截断或删除条目。

个人预设使用 `style` 与 `full` 两种范围。样式预设保存布局、外观、动画和行为，套用时保留内容；完整预设保存所有参数。预设绑定特效族与当前模板版本，不跨语义不同的特效族套用。开发期旧预设不做兼容读取。

## Pre-release Data Policy

首次正式发布前只支持当前特效族版本和当前持久化格式。现有 7 个开发期模板可以被直接删除或用新特效族替换，旧渲染器、版本迁移器、特效升级界面、`legacy-default` 回退和旧个人预设读取均不属于本里程碑。

开发期已有视频工作区、个人预设和视频模板允许清空或重建；加载到不兼容数据时应给出明确的开发期数据重建提示，不得悄悄猜测或迁移。模板版本字段继续保留，为首次正式发布后的兼容策略留下明确起点，但注册表只需包含当前版本。

旧基础转场可以直接移除。若未来重新提供全屏过渡遮罩，它属于装饰动画并使用独立稳定 ID，不计入本规格的 3 个片段转场特效族。

## True Transition Model

真实片段转场必须绑定两个当前相邻的视频片段 ID，而不是只保存一个任意时间范围。特效片段的时间放置使用可区分的范围放置和交界点放置；开发期旧片段不做自动迁移。

交界点放置由前视频片段、后视频片段和转场持续时间定义，实际起始帧从当前交界点派生。视频片段移动后只要两者仍相邻，转场跟随交界点；删除片段或改变顺序导致绑定失效时，同一次编辑命令移除无效转场并给出用户可见提示。

首阶段转场视觉窗口从后视频片段开始帧起算，后片段按正常源时间播放，前片段视觉在窗口内使用可用的尾部源帧继续渲染并逐步退出。前片段没有足够尾部源帧时冻结最后一个有效画面并显示非阻断警告。转场不改变项目总时长，音频仍在原交界点按现有开关和源音频规则衔接，不做音频交叉淡化。

转场渲染接口同时获得前后视频画面、局部帧、转场进度、画布和参数。普通信息叠加与装饰动画不得依赖相邻视频画面。

## Template Library And Discovery

模板库保留信息叠加、装饰动画和片段转场三个顶层类型，并增加：

- 按名称、特效用途标签和适用场景的文本搜索。
- 用途标签筛选与视觉方向辅助信息。
- 最近使用、个人预设和全部特效快捷入口。
- 特效族卡片与族内起始样式选择，不把同族样式伪装成无关模板。
- 只对可见、悬停或当前选中的卡片播放短动效预览；离屏卡片暂停并释放渲染负载。

模板库仍支持拖入时间轴和在播放头添加。片段转场只能添加到合法视频片段交界点；非法位置应给出可操作提示，不创建普通范围特效作为兜底。

## Responsive Layout

16:9 和 9:16 是所有 40 个起始样式的必测画幅，1:1 必须保持可见、可读且没有非预期溢出。每个特效族使用同一个渲染实现，通过画幅默认值、安全边距、容器约束和内容适配调整布局。

起始样式可以为不同画幅声明布局覆盖值。个人预设跨画幅应用时先合并目标画幅默认布局，再应用可兼容的用户参数，并向用户标识发生适配的布局字段。不得复制横屏版和竖屏版模板，也不得只对比例坐标做机械缩放。

## Visual And Technical Quality Gates

每个起始样式必须满足以下条件才能计入目录目标：

1. 为 16:9 和 9:16 分别生成入场、中段、出场固定帧基线；1:1 生成至少一个中段基线。
2. 覆盖默认值、最小值、最大值、长中英文文本、最大结构化条目数和高级越界场景。
3. 每个公开参数由契约测试证明会改变渲染输入、可观察画面或明确行为。
4. 相同输入和随机种子重复渲染得到稳定结果。
5. 浏览器过程预览和 Remotion 固定帧渲染使用同一特效族定义，并通过允许字体抗锯齿微差的自动图像比较。
6. 不出现非预期文字遮挡、空白画面、布局跳动、元素失控扩张或渲染异常。
7. 模板卡片离屏时不继续动画，40 个样式不能同时创建活跃播放器。
8. 属性面板控件具有可访问名称、键盘操作、错误或警告状态，并在深浅主题下可读。
9. 真实 MP4 冒烟测试至少覆盖一个信息叠加、一个装饰动画和一个真实片段转场。

视觉基线首次建立或有意更新时必须经过人工审阅。测试不得绑定内部 React 结构；特效开发基座的外部接口是行为测试 seam，固定帧是视觉测试 seam。

## Product Acceptance

- 用户可以通过搜索、用途标签或视觉预览在 30 秒内找到合适特效。
- 每个特效族的基础面板覆盖最高频调整，不要求用户先展开高级参数。
- 起始样式切换保留内容并支持一次撤销。
- 同一个特效可在横屏与竖屏画幅继续使用，不要求重新选择模板。
- 用户可以保存样式预设并应用到同一特效族的其他片段，也可以主动保存完整预设。
- 典型知识讲解视频可在 10 分钟内完成 3–5 个不同特效的添加、调整和过程预览。
- 模板库最终包含 15 个特效族和至少 40 个通过全部质量门槛的起始样式。

## Delivery Order

1. 建立特效族声明、参数 schema、确定性动画原语、素材槽位和视觉验证工具。
2. 升级属性面板、模板库、起始样式切换和个人预设流程，并删除已实现但不再需要的开发期兼容层。

## Risks And Mitigations

- **参数 schema 膨胀**：用固定参数分组、参数角色和少量复合控件保持接口稳定；特效特有行为留在族内实现，不为单个模板扩展编辑器核心。
- **万能特效族**：只有表达目的和主要时间行为相同的样式才能同族；语义不同即拆分特效族。
- **开发期脏数据误导测试**：验收前清空或重建视频工作区、个人预设和视频模板，并对不兼容格式给出明确提示。
- **转场缺少源素材尾帧**：冻结前片段最后有效画面并警告，不读取越界源帧或改变时间轴总时长。
- **字体和图标导出不一致**：只使用冻结的本地资源 ID，建立许可证台账并在构建时校验资源存在。
- **视觉快照噪声**：固定渲染环境、字体和随机种子，使用可解释阈值并要求人工审阅基线更新。
- **模板库性能下降**：虚拟化长列表，只播放可见或悬停预览，并对活跃播放器数量建立自动检查。
