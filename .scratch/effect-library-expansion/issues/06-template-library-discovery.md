# 06 — 特效族目录、搜索与按需动效预览

**What to build:** 让模板库按特效族展示起始样式，增加用途标签、视觉方向、搜索、最近使用和个人预设入口，并控制大量动效预览的运行成本。

**Blocked by:** 02 — 特效族深模块与参数契约；03 — 确定性渲染原语与内置素材槽位。

**Status:** ready-for-agent

- [ ] 保留信息叠加、装饰动画、片段转场三个顶层类型，并支持名称、用途标签和适用场景搜索。
- [ ] 特效族卡片可以查看和选择族内起始样式，不把同族样式伪装成无关模板。
- [ ] 增加全部特效、最近使用和个人预设快捷入口，最近使用不写入视频工作区数据。
- [ ] 只有可见、悬停或当前选中的卡片播放短动效预览，离屏卡片暂停并释放资源。
- [ ] 普通特效保留拖入时间轴和播放头添加；片段转场只能添加到合法交界点。
- [ ] 搜索、筛选、样式选择和拖放通过用户可观察行为测试，避免绑定内部 DOM 结构。
