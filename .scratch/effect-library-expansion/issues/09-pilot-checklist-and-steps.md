# 09 — 试点特效族：清单与步骤

**What to build:** 用清单与步骤特效族验证结构化内容、响应式排版、画幅默认值、交错动画和起始样式切换的完整垂直流程。

**Blocked by:** 03 — 确定性渲染原语与内置素材槽位；04 — 特效固定帧与视觉回归工具；05 — 分组属性面板与结构化参数控件。

**Status:** ready-for-human

- [x] 交付信息清单、编号步骤、横向流程 3 个起始样式。
- [x] 条目使用结构化内容参数，支持独立正文、重点文字、图标、强调色、增删和排序。
- [x] 支持字体、字号、对齐、间距、颜色、卡片外观和入场交错等基础与高级参数。
- [x] 为 16:9 与 9:16 提供不同默认布局，1:1 不溢出且保持可读。
- [x] 用新版清单与步骤特效族替换开发期信息清单卡，不保留 v1 渲染或升级入口。
- [x] 三个样式通过规格中的固定帧、参数矩阵、确定性和预览/导出一致性门槛。

## 人类验收

### 前置条件

- [ ] 执行 `npm run dev:all`，打开前端地址（通常为 `http://localhost:5173`）。
- [ ] 创建视频工作区并导入一段真实 MP4；准备横屏、竖屏和方形三个画幅，或通过项目设置切换画布。

### 操作与预期

- [ ] 在模板库中找到“清单与步骤”特效族，确认族卡片展示“信息清单”“编号步骤”“横向流程”三个起始样式，并能分别添加到时间轴。
- [ ] 分别添加三个样式，逐项编辑正文、重点文字、图标和强调色；新增、删除并拖动排序条目，确认条目顺序和字段值准确保留。
- [ ] 刷新或重新打开工作区，确认结构化条目仍以数组字段恢复，不依赖换行、逗号或竖线分隔。
- [ ] 在基础面板调整文字、位置、字号、颜色等高频参数，在高级面板调整字体、对齐、间距、卡片外观和入场交错；确认控件有可访问名称，非法值有错误或警告。
- [ ] 输入长中文、长英文和最大条目数，确认不发生文字遮挡、卡片失控扩张或空白画面；有意超过安全边界时只显示非阻断警告。
- [ ] 在 16:9、9:16 和 1:1 中分别检查可读性与边界；确认 16:9、9:16 使用不同合理默认布局，1:1 无非预期溢出。
- [ ] 修改内容、位置和时间范围后切换起始样式；确认内容和时间范围保留，默认位置/尺寸保留，确认预览中可选择采用目标画幅布局，并可用一次撤销恢复。
- [ ] 清空或重建含旧信息清单卡的开发期数据，确认模板库、项目数据和渲染路径只使用新版清单与步骤特效族。
- [ ] 对每个样式检查入场、中段、出场固定帧；重复相同输入和随机种子，确认结果稳定，且浏览器预览与 Remotion/MP4 输出一致。

### 放行证据

- [ ] 保存三个样式在 16:9、9:16、1:1 的入场/中段/出场截图或固定帧结果。
- [ ] 保存结构化条目增删排序、样式切换撤销和新版数据重开恢复的操作录屏或截图。
- [x] 记录自动化测试、视觉回归、真实 MP4 冒烟、类型检查和生产构建结果。
