# 01 — 冻结旧版特效兼容基线

**What to build:** 为现有 7 个模板、特效片段 JSON 和旧个人预设建立特征测试，明确新版基座必须保留的加载、默认参数和渲染行为。

**Status:** ready-for-agent

- [ ] 记录现有模板 ID、版本、类别、默认持续时间、参数默认值和公开名称，测试新版注册表不得静默改变这些值。
- [ ] 覆盖旧特效片段缺少特效族、起始样式和放置类型字段时的兼容读取。
- [ ] 覆盖旧个人预设缺少范围字段时按完整预设读取。
- [ ] 为章节标题卡、弹入卡片、信息清单卡、评论面板卡、标签胶囊组、漂浮气泡和基础转场保留可重复的代表帧输入。
- [ ] 明确旧基础转场是历史全屏覆盖效果，不把它自动迁移为真实片段转场。
