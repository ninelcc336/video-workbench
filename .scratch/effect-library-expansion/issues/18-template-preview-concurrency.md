# 18 — 模板库预览并发过高

**What to fix:** 滚动模板库时，多个模板卡片的动效预览会同时播放，造成不必要的渲染和主线程负载。

**Found during:** 06 — 特效族目录、搜索与按需动效预览的人类验收。

**Status:** needs-triage

- [ ] 滚动模板库时，同时运行的预览数量保持在明确的低上限内，不随目录总数增长。
- [ ] 只有当前可见、悬停或选中的卡片可以播放预览；离开可见区域的卡片及时停止并释放计时器或播放器。
- [ ] 在较长目录、快速滚动和 1280×800 / 1024×768 视口下验证滚动流畅度，并补充用户可观察行为测试或性能检查。
