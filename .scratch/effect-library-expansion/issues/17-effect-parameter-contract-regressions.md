# 17 — 特效参数契约回归与编辑闭环

**What to build:** 修复现有信息叠加特效在参数编辑后的结构丢失、控件不可交互和连续控件卡顿问题，并把“默认预设可用”扩展为“实际编辑后仍保持渲染结构和交互语义”。

**Blocked by:** 02 — 特效族深模块与参数契约；12 — 迁移现有信息叠加特效族。

**Status:** ready-for-agent

- [ ] 颜色选择器的色相、饱和度和明度连续拖动保持流畅；预览更新与历史记录提交分离，连续手势只提交一次最终值。
- [ ] 评论面板卡的“显示底部标签”可以鼠标和键盘操作，状态变更能立即反映到预览并正确持久化。
- [ ] 章节标题卡高级参数的“显示副标题”可以鼠标和键盘操作，状态变更能立即反映到预览并正确持久化。
- [ ] 标签胶囊组的标签内容使用规范化的结构化条目；编辑后仍渲染多个胶囊，不因写回单个字符串而合并为一个胶囊。
- [ ] 信息清单卡的清单内容使用规范化的结构化条目；编辑后仍渲染多个清单项，并在保存、重新打开和撤销重做后保持结构。
- [ ] 编辑器和渲染器共享同一份参数契约；重复内容不得以未声明的分隔符字符串作为项目最终数据。
- [ ] 为上述特效补充默认值、编辑值、持久化、撤销重做和预览结构一致性的回归测试。
- [ ] 在深浅主题、横竖画幅和人工交互流程中完成验收，记录控件不可用、内容结构变化和明显卡顿等非阻断问题。

## 问题归类

### 高频控件性能

颜色选择器的连续拖动存在明显卡顿风险，需检查高频 `pointermove` 是否触发全局状态更新、预览全量重渲染或重复历史记录写入。

### 参数显示但不可交互

评论面板卡的“显示底部标签”和章节标题卡的“显示副标题”已经出现在参数面板中，但无法点击。这类问题通常意味着控件的更新回调、禁用状态、键盘路径或事件层级没有和特效运行时正确连接。

### 重复内容的数据模型不一致

标签胶囊组和信息清单卡的默认效果能显示多个条目，但编辑内容后变成单个胶囊或单个清单。这说明默认预设与编辑器写回值可能使用了不同的数据形状，重复内容的边界在编辑过程中丢失。

### 特效编辑回归测试不足

只验证默认预设或面板控件存在，无法保证真实编辑后的预览仍保持原有结构。后续特效必须验证“默认值 → 编辑 → 保存/重开 → 撤销重做”的完整闭环。
