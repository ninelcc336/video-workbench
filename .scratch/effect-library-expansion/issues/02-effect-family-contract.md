# 02 — 特效族深模块与参数契约

**What to build:** 建立统一特效族声明和运行时接口，集中处理目录查询、默认实例化、参数归一化、样式切换、版本迁移和渲染输入。

**Blocked by:** 01 — 冻结旧版特效兼容基线。

**Status:** ready-for-agent

- [ ] 定义特效族、起始样式、特效用途标签、视觉方向、画幅默认值和版本迁移类型。
- [ ] 参数声明支持内容、布局、外观、动画、行为分组，以及基础/高级层级和样式切换保留策略。
- [ ] 参数值支持现有类型，并扩展多行文字、结构化列表、渐变、间距、字体、图标和动画阶段声明。
- [ ] 外部调用方通过统一模块完成查询、创建、验证、切换样式、升级和渲染输入生成，不读取族内实现细节。
- [ ] 校验结果区分阻断错误与非阻断警告，未知或非法值具有确定的回退行为。
- [ ] 通过模块接口测试行为，不为内部辅助函数复制同层测试。
