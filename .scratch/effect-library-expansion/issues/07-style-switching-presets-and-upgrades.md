# 07 — 起始样式切换、个人预设与显式特效升级

**What to build:** 实现保留内容的起始样式切换、样式/完整两种个人预设，以及可预览、可撤销的模板版本升级。

**Blocked by:** 02 — 特效族深模块与参数契约；05 — 分组属性面板与结构化参数控件；06 — 特效族目录、搜索与按需动效预览。

**Status:** ready-for-agent

- [ ] 起始样式切换始终保留内容和时间范围，默认保留位置与尺寸，只替换外观、动画和行为。
- [ ] 新样式无法容纳原内容时先展示差异和警告，不截断或删除结构化条目。
- [ ] 切换样式通过一条编辑命令提交并支持一次撤销。
- [ ] 个人预设持久化增加 `style` 与 `full` 范围；旧预设缺少范围时按完整预设读取。
- [ ] 样式预设套用时不覆盖内容，完整预设恢复所有兼容参数；两者都校验特效族和模板版本。
- [ ] 特效升级先展示迁移参数、默认项、丢弃项和警告，确认后一次提交并可撤销。
- [ ] 打开或反序列化视频工作区不得自动升级模板版本。
