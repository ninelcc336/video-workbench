# 12 — 迁移现有信息叠加特效族

**What to build:** 在三个试点证明基座接口稳定后，将现有章节标题、卡片、评论和标签模板迁入新版特效族并扩展到 12 个合格起始样式。

**Blocked by:** 07 — 起始样式切换、个人预设与显式特效升级；09 — 试点特效族：清单与步骤；10 — 试点特效族：手绘重点标注；11 — 试点特效族：方向推拉与擦除。

**Status:** ready-for-agent

- [ ] 标题层交付简洁章节、科技编号、活力大标题 3 个起始样式。
- [ ] 重点卡片交付实色卡片、玻璃卡片、描边卡片 3 个起始样式。
- [ ] 引用与评论交付引用卡、评论卡、对话气泡 3 个起始样式。
- [ ] 标签与状态交付标签胶囊、状态徽章、标签云 3 个起始样式。
- [ ] 每个族补齐字体、布局、外观、三段式动画和画幅适配参数，不只包装旧实现。
- [ ] 四个旧 v1 模板保持原渲染，并提供可预览、可撤销的显式升级。
- [ ] 12 个样式全部通过规格质量门槛。

## 人类验收

### 前置条件

- [ ] 执行 `npm run dev:all`，打开前端地址（通常为 `http://localhost:5173`）。
- [ ] 准备包含章节标题卡、弹入卡片、信息清单卡、评论面板卡和标签胶囊组的旧版工作区或固定测试数据。

### 操作与预期

- [ ] 在模板库中确认新版信息叠加目录包含标题层、重点卡片、引用与评论、标签与状态四个特效族，以及对应 12 个起始样式。
- [ ] 逐个添加 12 个样式，确认它们共享族级渲染实现，但在字体、布局、外观、入场/持续/出场动画和画幅默认值上有明确设计差异，不只是颜色替换。
- [ ] 对每个族检查基础面板的 5–8 个高频参数、高级分组参数、结构化字段、字体/图标素材槽位和安全布局警告；确认不需要为单个族新增专用属性面板代码。
- [ ] 在 16:9、9:16 和 1:1 中验证文字可读、内容不遮挡、元素不溢出；切换样式时确认内容和时间范围保留，默认位置/尺寸保留，升级布局可在确认预览中选择。
- [ ] 打开每个旧 v1 模板，确认加载、预览和导出视觉保持原样；确认打开工作区不会自动升级模板版本或参数。
- [ ] 从升级入口逐个预览旧模板到新版族的迁移，检查参数变更、默认项、丢弃项和警告；取消不改动，确认后一次提交，并验证撤销恢复旧版本。
- [ ] 验证样式预设只覆盖布局/外观/动画/行为而不覆盖内容，完整预设恢复兼容内容；旧版预设缺少范围字段时按完整预设读取。
- [ ] 对 12 个样式执行固定帧、参数矩阵、随机种子重复渲染、浏览器预览与 Remotion/MP4 一致性检查。
