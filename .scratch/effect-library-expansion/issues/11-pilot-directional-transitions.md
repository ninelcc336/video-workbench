# 11 — 试点特效族：方向推拉与擦除

**What to build:** 在真实双画面合成器上交付方向推拉与擦除特效族，验证交界点选择、转场时序和尾部源帧不足回退。

**Blocked by:** 04 — 特效固定帧与视觉回归工具；08 — 交界点放置与双画面转场合成器。

**Status:** ready-for-agent

- [ ] 交付推拉、方向擦除、分割擦除 3 个起始样式。
- [ ] 支持方向、持续时间、缓动、边界柔化、分割数量和强调色等适用参数。
- [ ] 只能在合法相邻视频片段交界点创建，并在模板库和时间轴中提供明确反馈。
- [ ] 覆盖视频片段移动、删除、重排、源尾帧充足和源尾帧不足场景。
- [ ] 转场不改变项目总时长和现有音频结果。
- [ ] 三个样式通过前画面、中间混合、后画面固定帧与真实 MP4 冒烟测试。
