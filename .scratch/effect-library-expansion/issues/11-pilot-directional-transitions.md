# 11 — 试点特效族：方向推拉与擦除

**What to build:** 在真实双画面合成器上交付方向推拉与擦除特效族，验证交界点选择、转场时序和尾部源帧不足回退。

**Blocked by:** 04 — 特效固定帧与视觉回归工具；08 — 交界点放置与双画面转场合成器。

**Status:** ready-for-human

- [x] 交付推拉、方向擦除、分割擦除 3 个起始样式。
- [x] 支持方向、持续时间、缓动、边界柔化、分割数量和强调色等适用参数；持续时间沿用交界点特效片段的 `durationInFrames`，由时间轴调整并从当前交界点派生窗口。
- [x] 只能在合法相邻视频片段交界点创建，并在模板库和时间轴中提供明确反馈。
- [x] 覆盖视频片段移动、删除、非相邻绑定失效、源尾帧充足和源尾帧不足场景；绑定失效会在同一编辑命令移除并通知。
- [x] 转场不改变项目总时长和现有音频结果；真实转场画面节点静音，音频继续由主视频轨道按原规则输出。
- [x] 三个样式通过前画面、中间混合、后画面固定帧与真实 MP4 冒烟测试。

## 人类验收

### 前置条件

- [ ] 执行 `npm run dev:all`，打开前端地址（通常为 `http://localhost:5173`）。
- [ ] 创建工作区并导入两段内容明显不同的真实 MP4，将它们放在主视频轨道上形成合法交界点；准备一组前片段尾帧不足的素材。

### 操作与预期

- [ ] 在模板库中找到“方向推拉与擦除”特效族，确认“推拉”“方向擦除”“分割擦除”三个起始样式均可见。
- [ ] 在合法相邻视频片段交界点添加三个样式，确认转场绑定前后视频片段 ID；在非交界点尝试添加，确认收到可操作提示且不会创建普通范围特效。
- [ ] 分别调整方向、持续时间、缓动、边界柔化、分割数量和强调色，确认前后画面变化符合参数语义，且没有超出声明的渲染安全上限。
- [ ] 移动前片段或后片段，确认转场仍跟随交界点；删除片段或改变顺序使绑定失效时，确认同一次编辑会移除无效转场并显示用户可见提示。
- [ ] 在转场窗口检查前画面逐步退出、中间帧混合和后画面正常进入；确认后片段按正常源时间播放。
- [ ] 使用尾部源帧不足的前片段，确认冻结最后一个有效画面并显示非阻断警告，不读取越界源帧、不改变总时长。
- [ ] 验证项目总时长、交界点音频衔接和音频开关保持原规则，确认没有引入音频交叉淡化。
- [ ] 在 16:9、9:16、1:1 和不同视频分辨率下检查转场边界、遮罩和可读性；确认三个样式均同时消费前后视频画面，而不是纯色覆盖层。
