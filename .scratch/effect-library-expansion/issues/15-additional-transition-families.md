# 15 — 新增其余片段转场特效族

**What to build:** 在方向转场试点基础上新增几何遮罩与淡化、闪白和色彩过渡，完成真实片段转场目录。

**Blocked by:** 07 — 起始样式切换、个人预设与显式特效升级；11 — 试点特效族：方向推拉与擦除。

**Status:** ready-for-agent

- [ ] 几何遮罩交付圆形展开、斜切多边形、分块遮罩 3 个起始样式。
- [ ] 淡化、闪白与色彩过渡交付交叉淡化、闪白色彩过渡 2 个起始样式。
- [ ] 所有样式同时消费前后视频画面，不以纯色覆盖层冒充片段转场。
- [ ] 支持持续时间、缓动、方向、遮罩柔化、色彩和强度等适用参数。
- [ ] 覆盖横屏、竖屏、不同视频分辨率、尾部源帧不足和历史基础转场共存场景。
- [ ] 5 个样式全部通过规格质量门槛，使片段转场达到 3 族、8 样式。

## 人类验收

### 前置条件

- [ ] 执行 `npm run dev:all`，打开前端地址（通常为 `http://localhost:5173`）。
- [ ] 准备两段内容明显不同的真实 MP4、两种以上分辨率，并准备前片段尾帧不足的短素材。

### 操作与预期

- [ ] 在模板库中找到“几何遮罩”和“淡化、闪白与色彩过渡”两个特效族，确认圆形展开、斜切多边形、分块遮罩、交叉淡化、闪白色彩过渡 5 个样式均可添加。
- [ ] 在合法相邻视频片段交界点添加每个样式，确认转场绑定前后片段；在任意范围或非法位置添加时，确认提示可操作且不会退化为普通范围特效。
- [ ] 检查每个样式同时消费前后视频画面：前画面、中间混合和后画面均应可观察，不能只是纯色覆盖层或只读取单个片段。
- [ ] 分别调整持续时间、缓动、方向、遮罩柔化、色彩和强度，确认参数语义有效且不会产生空白画面、跳变或异常扩张。
- [ ] 移动、删除和重排相邻视频片段，确认转场跟随仍合法；绑定失效时一次性移除并显示提示。
- [ ] 在尾部源帧不足时确认冻结最后一个有效前画面并显示非阻断警告，不读取越界帧、不改变项目总时长、不引入音频交叉淡化。
- [ ] 在横屏、竖屏、1:1 和不同视频分辨率下检查遮罩边界、混合结果和可读性；与历史基础转场共存时确认旧版本视觉不变。
- [ ] 对 5 个样式执行前画面、中间混合、后画面固定帧、真实 MP4 冒烟和浏览器预览/Remotion 导出一致性检查。

### 放行证据

- [ ] 保存 5 个样式在三种画幅的前/中/后固定帧或视觉回归结果。
- [ ] 保存合法/非法添加、绑定跟随、绑定失效、尾帧冻结和项目总时长/音频对比证据。
- [ ] 记录至少一个真实双画面转场 MP4、自动化测试、视觉回归、类型检查和生产构建结果。
