# 14 — 新增其余装饰动画特效族

**What to build:** 新增箭头与引导线、聚焦与扫描，并将漂浮气泡迁入几何点缀与粒子，完成装饰动画目录。

**Blocked by:** 07 — 起始样式切换、个人预设与兼容层清理；10 — 试点特效族：手绘重点标注；11 — 试点特效族：方向推拉与擦除。

**Status:** ready-for-agent

- [ ] 箭头与引导线交付脉冲直箭头、手绘曲线箭头 2 个起始样式。
- [ ] 聚焦与扫描交付聚光区域、扫描框 2 个起始样式。
- [ ] 几何点缀与粒子交付漂浮气泡、几何粒子流 2 个起始样式。
- [ ] 支持密度、速度、循环、强度、路径、颜色和随机种子等适用参数，并设渲染安全上限。
- [ ] 用新版几何点缀与粒子特效族替换开发期漂浮气泡，不保留 v1 渲染或升级入口。
- [ ] 6 个样式全部通过规格质量门槛，使装饰动画达到 4 族、10 样式。

## 人类验收

### 前置条件

- [ ] 执行 `npm run dev:all`，打开前端地址（通常为 `http://localhost:5173`）。
- [ ] 准备带有明显主体和安全边界的真实视频，以及可观察粒子、扫描和引导动作的画面。

### 操作与预期

- [ ] 在模板库中确认“箭头与引导线”“聚焦与扫描”“几何点缀与粒子”三个特效族及 6 个起始样式均可添加。
- [ ] 分别调整脉冲直箭头、手绘曲线箭头、聚光区域、扫描框、漂浮气泡和几何粒子流，确认路径、密度、速度、循环、强度、颜色和随机种子等参数行为符合语义。
- [ ] 设置最小、默认和最大密度/粒子数量，确认渲染安全上限生效；超过安全范围时阻止或回退到明确默认值，并展示可理解的提示。
- [ ] 固定随机种子后暂停、跳帧、刷新和导出，确认装饰路径、粒子分布和循环相位稳定，不依赖真实时间或无种子随机数。
- [ ] 在 16:9、9:16 和 1:1 中检查主体遮挡、边界可见性和画幅默认布局；基础模式保持可见，高级模式允许越界时显示非阻断警告。
- [ ] 检查模板库大量卡片预览：离屏卡片应暂停并释放渲染负载，可见/悬停/当前选中卡片才播放，活跃播放器数量不会随目录数量线性增长。
- [ ] 确认旧漂浮气泡模板不再注册或出现在模板库，项目数据和渲染路径只使用新版几何点缀与粒子特效族。
- [ ] 对 6 个样式执行入场、中段、出场固定帧、浏览器预览与 Remotion/MP4 一致性检查，并确认深浅主题下参数警告可读。

### 放行证据

- [ ] 保存随机种子稳定性、粒子安全上限、离屏预览暂停和旧模板入口已移除的操作证据。
- [ ] 记录性能检查、真实 MP4、视觉回归、类型检查和生产构建结果。
