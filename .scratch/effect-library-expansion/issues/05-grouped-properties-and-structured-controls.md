# 05 — 分组属性面板与结构化参数控件

**What to build:** 将扁平属性面板升级为基础/高级渐进式编辑器，并为新版参数 schema 提供可访问、可校验的控件。

**Blocked by:** 02 — 特效族深模块与参数契约。

**Status:** resolved

- [x] 基础面板只展示特效族声明的 5–8 个高频参数，高级面板按内容、布局、外观、动画和行为折叠分组。
- [x] 为数字范围提供滑杆与精确输入，为枚举提供菜单或分段控件，为颜色和渐变提供色板，为布尔值提供开关。
- [x] 提供多行文字、可排序结构化条目、字体、图标、间距和动画阶段控件。
- [x] 结构化条目支持增删、排序、字段校验和多行文本批量粘贴，不把分隔符字符串写回项目。
- [x] 基础模式执行安全布局保护，高级模式显示越界、低对比、长文本和高负载警告。
- [x] 每个参数分组支持单独重置；一次连续手势只形成一条可撤销编辑历史。
- [x] 所有控件具有可访问名称、键盘操作、错误与警告状态，并在深浅主题下保持可读。
