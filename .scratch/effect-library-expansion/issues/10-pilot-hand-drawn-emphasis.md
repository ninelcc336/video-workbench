# 10 — 试点特效族：手绘重点标注

**What to build:** 用手绘重点标注特效族验证 SVG 路径、确定性随机、画布直接调整、持续动画和高级越界能力。

**Blocked by:** 03 — 确定性渲染原语与内置素材槽位；04 — 特效固定帧与视觉回归工具；05 — 分组属性面板与结构化参数控件。

**Status:** ready-for-agent

- [ ] 交付手绘下划线、荧光笔、圈选、方框 4 个起始样式。
- [ ] 支持位置、尺寸、旋转、颜色、粗细、粗糙度、路径方向、绘制时长和随机种子。
- [ ] 相同随机种子在过程预览、跳帧和 Remotion 导出中生成相同路径。
- [ ] 基础模式保持标注可见，高级模式允许越界和裁切并显示警告。
- [ ] 画布拖动、缩放与属性面板共享同一过程预览参数，不为连续手势制造多条历史。
- [ ] 四个样式通过规格中的固定帧、参数矩阵、确定性和预览/导出一致性门槛。

## 人类验收

### 前置条件

- [ ] 执行 `npm run dev:all`，打开前端地址（通常为 `http://localhost:5173`）。
- [ ] 创建视频工作区并导入真实 MP4；准备 16:9、9:16 和 1:1 画布，以及一段可观察标注位置的画面。

### 操作与预期

- [ ] 在模板库中找到“手绘重点标注”特效族，确认“手绘下划线”“荧光笔”“圈选”“方框”四个起始样式均可添加。
- [ ] 分别调整位置、尺寸、旋转、颜色、粗细、粗糙度、路径方向和绘制时长，确认每个公开参数会改变画面或明确行为。
- [ ] 在基础模式中将标注拖动到画布边缘，确认标注仍可见且编辑安全；在高级模式中有意移出安全区域或裁切，确认出现非阻断警告而不是静默改值。
- [ ] 用画布拖动和缩放连续调整标注，确认属性面板、画布和预览同步更新，松手后只产生一条编辑历史；撤销一次应恢复手势前状态。
- [ ] 设置固定随机种子，反复暂停、跳帧、刷新并导出，确认手绘路径和粗糙度保持一致，不随真实时间变化。
- [ ] 切换四个起始样式，确认内容、时间范围和默认位置/尺寸规则符合预览提示，并可一次撤销。
- [ ] 在 16:9、9:16 和 1:1 中检查标注可见性、边界和文字/画面遮挡；确认深色与浅色主题下属性面板警告可读。
- [ ] 对四个样式检查入场、中段、出场固定帧，确认绘制、持续和出场阶段没有跳变、空白或布局抖动。

### 放行证据

- [ ] 保存四个样式在三种画幅和三个动画阶段的固定帧截图或视觉回归结果。
- [ ] 保存随机种子重复预览、画布连续手势、越界警告和撤销行为的操作证据。
- [ ] 保存至少一个真实 MP4 导出，并记录自动化测试、视觉回归、类型检查和生产构建结果。
