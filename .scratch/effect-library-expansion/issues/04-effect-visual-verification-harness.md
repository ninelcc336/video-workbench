# 04 — 特效固定帧与视觉回归工具

**What to build:** 建立以特效族外部接口为输入的固定帧渲染、截图比较和参数矩阵工具，让每个起始样式都能自动验证横竖画幅和极端输入。

**Blocked by:** 02 — 特效族深模块与参数契约；03 — 确定性渲染原语与内置素材槽位。

**Status:** resolved

- [x] 自动生成 16:9、9:16 的入场、中段、出场帧，以及 1:1 中段帧。
- [x] 参数矩阵覆盖默认值、最小值、最大值、长中英文文本、最大结构化条目数和高级越界。
- [x] 浏览器过程预览截图与 Remotion 固定帧使用同一输入，并通过允许字体抗锯齿微差的图像比较。
- [x] 固定渲染环境、字体和随机种子；基线新增或更新时输出便于人工审阅的差异图。
- [x] 提供单个特效族、单个起始样式和全目录三种运行范围，失败信息包含族、样式、画幅、帧和参数场景。
- [x] 将视觉验证命令接入项目脚本，但不让日常快速单元测试强制执行全部截图矩阵。

## Comments
