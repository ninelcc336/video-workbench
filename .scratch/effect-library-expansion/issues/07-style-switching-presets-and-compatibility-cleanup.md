# 07 — 起始样式切换、个人预设与兼容层清理

**What to build:** 实现保留内容的起始样式切换和样式/完整两种个人预设，并删除开发期旧模板、旧预设和显式版本升级兼容层。

**Blocked by:** 02 — 特效族深模块与参数契约；05 — 分组属性面板与结构化参数控件；06 — 特效族目录、搜索与按需动效预览。

**Status:** resolved

- [x] 起始样式切换始终保留内容和时间范围，默认保留位置与尺寸，只替换外观、动画和行为。
- [x] 新样式无法容纳原内容时先展示差异和警告，不截断或删除结构化条目。
- [x] 切换样式通过一条编辑命令提交并支持一次撤销。
- [x] 个人预设持久化使用 `style` 与 `full` 范围。
- [x] 样式预设套用时不覆盖内容，完整预设恢复所有当前参数；两者都校验特效族和当前模板版本。
- [x] 删除旧预设兼容读取、旧特效片段兼容元数据、版本迁移注册和显式特效升级界面。
- [x] 不兼容的开发期视频工作区或预设返回明确的重建提示，不猜测或自动迁移数据。
- [x] 清理兼容层后删除因此失去用途的类型、函数、测试和界面文案，并重新通过全量验证。
