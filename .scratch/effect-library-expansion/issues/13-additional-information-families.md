## 人类验收

### 前置条件

- [ ] 执行 `npm run dev:all`，打开前端地址（通常为 `http://localhost:5173`）。
- [ ] 准备包含人物信息、名词解释、来源说明、重点数字、进度指标、左右差异和结论判断的知识讲解视频素材。

### 操作与预期

- [ ] 在模板库中找到“下三分之一信息条”“数据与数字”“对比与结论”三个特效族，并确认 7 个起始样式全部可添加。
- [ ] 分别使用人物身份、名词定义、信息来源、重点数字、进度指标、左右对比和结论章内容，确认字段语义与族用途一致；结构化字段可增删排序且不会退化为分隔符文本。
- [ ] 检查素材槽位只引用内置字体、图标等稳定资源 ID，不出现绝对路径、远程 URL 或用户任意上传入口。
- [ ] 在基础模式完成常见调整，在高级模式调整字体、布局、外观、三段式动画和行为；确认参数变化能改变渲染输入、画面或明确行为。
- [ ] 在 16:9、9:16、1:1 中检查默认布局、安全边距、长中英文内容和最大条目数；越界、低对比、过长文本和高负载场景应给出非阻断警告。
- [ ] 验证 7 个样式覆盖简洁信息、科技数据和活力社媒视觉方向，确认视觉差异不只是颜色变化。
- [ ] 在每个族内切换起始样式，确认内容、时间范围和默认位置/尺寸规则正确；分别验证样式预设、完整预设和一次撤销。
- [ ] 对 7 个样式执行入场、中段、出场固定帧、重复随机种子、浏览器预览与 Remotion/MP4 一致性检查。
