# 08 — 交界点放置与双画面转场合成器

**What to build:** 扩展特效片段放置模型，使真实片段转场绑定相邻视频片段，并在不改变项目总时长和音频规则的前提下同时合成前后画面。

**Blocked by:** 01 — 冻结旧版特效兼容基线；02 — 特效族深模块与参数契约；03 — 确定性渲染原语与内置素材槽位。

**Status:** ready-for-agent

- [ ] 将特效片段放置建模为范围放置与交界点放置的可区分类型，旧片段兼容读取为范围放置。
- [ ] 交界点放置保存前后视频片段 ID 和持续时间，实际帧位置从当前交界点派生。
- [ ] 视频片段移动后仍相邻时转场跟随；删除或重排导致绑定失效时，同一编辑命令移除转场并提示用户。
- [ ] 转场窗口从后视频片段开始帧起算，后片段正常播放，前片段使用可用尾部源帧继续渲染并退出。
- [ ] 前片段尾部源帧不足时冻结最后有效画面并给出非阻断警告，不读取越界帧。
- [ ] 渲染接口同时提供前后画面、局部帧、进度、画布与参数；普通特效仍使用单画面接口。
- [ ] 音频保持现有交界点衔接，不引入交叉淡化；项目总时长不因转场变化。
- [ ] 旧基础转场保留 v1 渲染并从新目录隐藏，不自动变为交界点转场。
