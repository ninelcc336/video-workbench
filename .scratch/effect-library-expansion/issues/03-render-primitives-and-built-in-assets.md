# 03 — 确定性渲染原语与内置素材槽位

**What to build:** 提供特效族可复用的 2D 文字、卡片、线条、遮罩、粒子和三段式动画原语，并建立只引用本地稳定 ID 的字体与图标素材槽位。

**Blocked by:** 02 — 特效族深模块与参数契约。

**Status:** ready-for-agent

- [ ] 实现可任意帧求值的入场、持续、出场阶段，支持独立时长、延迟、缓动、方向、强度和交错。
- [ ] 实现带种子的确定性随机工具，禁止模板读取真实时间或使用无种子的随机数。
- [ ] 提供响应画幅的文字适配、卡片、描边、阴影、渐变、遮罩、路径绘制和轻量粒子原语。
- [ ] 内置字体、图标和装饰素材通过稳定资源 ID 解析，浏览器预览与 Remotion 渲染使用同一冻结文件。
- [ ] 建立资源来源与许可证台账，并在构建时检查缺失文件或非法远程引用。
- [ ] 动画总时长超过片段时按稳定规则压缩并返回警告，不产生负帧或跳变。
