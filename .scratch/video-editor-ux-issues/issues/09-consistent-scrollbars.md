# 统一编辑器滚动条视觉样式

Category: enhancement
Status: resolved

## Agent Brief

**Category:** enhancement
**Summary:** 让页面内所有滚动条使用与编辑器暗色荧光风格一致的轻量样式，移除浏览器默认滚动条外观。

**Current behavior:**

编辑器通过多个内部滚动容器承载超出内容，包括素材与模板库、分类标签、特效参数面板和底部时间轴。当前样式只声明了这些容器的溢出行为，没有统一的滚动条颜色、尺寸、圆角或悬停状态，因此不同浏览器会显示默认滚动条，破坏编辑器整体视觉一致性。

**Desired behavior:**

所有实际产生滚动条的页面和内部容器都应复用一套与编辑器配色一致的滚动条主题：暗色轨道、低调但可辨认的橄榄绿色滑块、圆角和悬停反馈。样式需要同时覆盖支持标准 `scrollbar-color`/`scrollbar-width` 的浏览器以及基于 `::-webkit-scrollbar` 的浏览器；必须保留足够的滑块可见性和可操作面积，不应通过隐藏滚动条来达成视觉统一。无需引入第三方滚动条组件，除非原生 CSS 无法覆盖某个已存在的滚动场景。

**Key interfaces:**

- 全局滚动条 CSS 契约：页面根节点和所有滚动容器共享同一套颜色、厚度和交互状态。
- 现有内部滚动容器：不改变其 `overflow` 方向、布局尺寸或滚动边界，仅补充视觉主题。
- 编辑器颜色变量：滚动条主题应复用编辑器现有暗色背景与荧光绿色视觉语言，避免新增无法解释的独立主题。

**Acceptance criteria:**

- [x] 页面根节点及左侧素材/模板库、分类标签、右侧特效参数面板、底部时间轴的滚动条均不再使用浏览器默认外观。
- [x] 滚动条同时提供标准属性和 WebKit 伪元素兜底，纵向与横向滚动条都具备一致的尺寸、轨道、滑块和圆角风格。
- [x] 滑块在静止、悬停和按下状态下均可辨认，并保持可操作；不能使用 `display: none` 或等效方式隐藏滚动条。
- [x] 滚动条主题与现有编辑器暗色背景、荧光绿色强调色一致，不改变现有滚动容器的方向、尺寸和滚动行为。
- [x] 增加自动化样式契约测试，覆盖标准属性、WebKit 伪元素以及悬停状态；现有类型检查和测试套件通过。

**Out of scope:**

- 改变三栏编辑器布局、各面板高度或时间轴交互逻辑。
- 引入重量级第三方滚动条组件或重写原生滚动行为。
- 为编辑器增加亮色主题、主题切换或新的设计系统。
