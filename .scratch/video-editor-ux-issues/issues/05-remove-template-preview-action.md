# 移除特效模板卡片上的“预览”操作

Category: enhancement  
Status: needs-triage

## Summary

简化左侧“特效模板”卡片的操作，把“预览”从当前模板卡片交互中移除，避免用户把它误认为主要编辑入口。

## Current behavior

每个特效模板卡片同时提供动效缩略区域、“预览/停止”按钮和“添加”按钮。用户认为左侧预览操作价值不高，希望移除“预览”。

## Desired behavior

左侧模板库保留模板卡片中的动效缩略预览，但不再显示或触发独立的“预览/停止”按钮，主要操作聚焦于选择和添加模板。

## Acceptance criteria

- [ ] 模板卡片不再显示文案为“预览”或“停止”的操作按钮。
- [ ] “添加弹入卡片”和“添加漂浮气泡”等添加操作仍然可用。
- [ ] 模板卡片拖拽到时间轴的行为不受影响。
- [ ] 移除操作后，模板库不再维护无用的预览播放状态或定时器。

## Out of scope

- 不移除模板卡片顶部的动效缩略预览区域。
- 不改变中间实时预览区域。
- 不改变模板筛选分类和拖拽添加流程。

## Initial triage notes

现有模板卡片确实同时实现了内嵌动效和独立预览按钮；用户已确认只移除“预览/停止”按钮，保留动效缩略预览。仍先保留 `needs-triage`，等待维护者完成最终分派。
