# 特效片段全部落在同一条轨道，重叠时难以定位和编辑

Category: enhancement  
Status: needs-triage

## Summary

让多个特效片段在时间轴中拥有可辨认的独立轨道或自动分层，避免重叠片段全部堆在一条“特效轨道”上导致定位和选择困难。

## Current behavior

编辑项目的数据模型已有 `trackId`，但通过模板库添加或拖放创建的特效片段都使用 `effects-1`，时间轴也只渲染一条特效轨道。因此两个或多个时间范围重叠的特效片段会处于同一行，用户难以看清顺序、选中目标或调整范围。

## Desired behavior

时间轴应根据特效片段的轨道归属显示多条特效轨道，或者根据时间范围自动分配不重叠的可见轨道。每个特效片段都应显示名称、起止范围和选中状态，并保持其在预览中的时间位置不变。

## Acceptance criteria

- [ ] 同时添加两个时间范围重叠的特效片段时，它们不会在同一行完全遮挡，用户可以分别选中和拖动。
- [ ] 时间轴能够显示至少两条可辨认的特效轨道，并为每条轨道提供稳定标签。
- [ ] 片段移动或调整持续时间后，轨道布局重新计算或保持有效，不会隐藏片段。
- [ ] 轨道显示位置与 `EffectClip.fromFrame`、`durationInFrames` 一致，不能改变预览中的生效时间。
- [ ] 保存、加载、撤销和重做后，特效片段的轨道归属不会丢失或互相覆盖。
- [ ] 不重叠的特效片段可以保持紧凑布局，不要求无意义地创建无限轨道。

## Out of scope

- 增加多条主视频轨道。
- 引入关键帧、音频轨道或复杂剪辑能力。
- 改变特效模板的视觉渲染逻辑。

## Related implementation concepts

- `EffectClip.trackId`：特效片段的轨道归属。
- `Timeline`：根据项目快照渲染轨道和片段。
- `add-effect-clip`：新增特效片段时决定初始轨道归属。
- `0004-single-video-track-timeline`：当前 ADR 允许一条主视频轨道和多条特效轨道。

## Initial triage notes

静态检查确认新增特效和拖放创建都固定写入 `effects-1`，而时间轴只绘制一个特效轨道；这与 ADR 中“多条特效轨道”的模型意图不一致。需要维护者确认期望是自动避让分层，还是允许用户手动新建和选择特效轨道。
