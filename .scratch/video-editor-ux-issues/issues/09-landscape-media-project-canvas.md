# 横屏素材首次导入时应匹配自身比例的编辑项目

Category: enhancement
Status: resolved

## Summary

当横屏视频素材成为主视频轨道上的首个片段时，自动采用与素材相同纵横比的横屏编辑项目，使素材在实时预览中完整铺满画布而不产生留白。

## Current behavior

新编辑项目默认采用竖屏规格。素材导入流程不读取视频的宽高方向，因此横屏视频被放入竖屏编辑项目后，按完整显示规则出现留白。虽然导出对话框提供横屏规格，但它不会更新编辑项目的画布。

## Desired behavior

向主视频轨道为空的编辑项目导入首个横屏素材时，编辑项目在创建视频片段前以 `1920` 为横向基准、按素材原始宽高比推导画布高度，并使默认导出规格保持相同尺寸和比例。已有特效片段不阻止本次匹配，因为其位置使用相对参数。实时预览继续按编辑项目比例放大；因为画布与横屏素材匹配，素材应完整铺满画布而不裁剪或变形。竖屏素材维持现有竖屏默认行为。

当主视频轨道为空且导入的视频素材宽度大于高度时，在创建视频片段前将 `EditProject.settings` 和默认 `EditProject.export` 同步为与素材相同比例的横屏规格：宽度以 `1920` 为基准，高度由素材宽高比推导。已有特效片段保留其相对参数，不阻止画布匹配。预览与导出继续使用同一份编辑项目数据和 `EditorComposition`，让横屏素材在横屏画布中完整显示、无拉伸、无裁剪。竖屏和方形素材维持现有默认画布行为。

**Key interfaces:**
- 媒体导入管线 — 应提供可靠的视频宽高，以便在创建首个视频片段前判定素材方向。
- `EditProject.settings` 与 `EditProject.export` — 首个横屏素材应使两者使用一致的横屏规格。
- 编辑项目创建与素材加入命令 — 仅在主视频轨道尚未包含视频片段时允许自动匹配画布；已有特效片段不阻止匹配，避免改写已有主视频布局。
- `EditorComposition` — 继续作为浏览器预览和 MP4 导出的唯一视觉定义。

- [x] 该横屏素材在预览中按完整显示规则铺满横屏画布，不产生竖屏留白、拉伸或裁剪。
- [x] 首次导入竖屏或方形素材时，保留当前默认画布和导出规格。
