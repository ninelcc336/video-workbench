# 调整特效参数后，预览画面没有视觉变化

Category: bug  
Status: resolved

## Summary

修复右侧特效参数面板和预览画布的修改，使参数变化立即反映到实时预览，并保存在编辑项目的特效片段中。

## Current behavior

用户添加特效后调整文字、颜色、位置、尺寸或动画参数，反馈预览画面没有变化，像是参数控件没有生效。

代码中已有参数声明、参数规范化、属性面板回调、编辑器命令 `update-effect-params` 以及画布拖拽调整链路，但需要确认参数合并后的项目快照是否重新传入 Player，以及模板是否读取到最新参数。

## Desired behavior

每次合法参数修改后，预览应立即使用最新的特效参数重新渲染；右侧控件、画布选区和项目快照中的值保持一致，保存或重新打开项目后仍然使用修改后的值。

## Acceptance criteria

- [x] 修改“弹入卡片”的文字、卡片颜色、文字颜色、位置和尺寸后，预览分别出现对应变化。
- [x] 修改“漂浮气泡”的颜色、位置、尺寸、透明度和数量后，预览分别出现对应变化。
- [x] 通过右侧参数面板修改后，编辑项目中的对应 `EffectClip.params` 更新，且不会修改旧快照。
- [x] 通过预览画布拖动或缩放后，参数面板显示最新位置和尺寸。
- [x] 非法或越界参数仍由现有规范化和校验规则处理，不得导致预览崩溃。
- [x] 至少有组件或端到端测试验证修改参数后预览输入快照发生变化。

## Out of scope

- 增加新的参数类型或新的模板参数。
- 重新设计属性面板的整体布局。
- 修复特效完全不显示的问题；该问题单独记录在 issue 03。
