# 实时预览视频控制栏未适配工作区布局

Category: enhancement
Status: resolved

## Summary

调整实时预览的视频控制栏，使其适配类似剪映的预览工作区：视频画布专注于展示画面，播放控制独立放置在工作区底部，不遮挡视频内容。

## Current behavior

当前 `PreviewPlayer` 使用 Remotion `Player` 的默认 `controls`。默认控制栏以绝对定位方式叠加在实际视频画布底部。虽然外层 `preview-device` 已改为铺满中间工作区，但控制栏仍然属于内部画布的一部分，视觉上会遮挡画面，也没有形成独立的工作区控制区域。

## Desired behavior

视频画布与视频控制栏在布局上分离。控制栏固定在实时预览工作区底部，并提供清晰可用的播放/暂停、进度定位和当前时间信息；控制操作继续驱动 Remotion Player，并与页面当前帧、时间轴播放头保持同步。

## Acceptance criteria

- [x] 视频画布区域不再被默认控制栏遮挡。
- [x] 控制栏位于实时预览工作区底部，与横屏和竖屏画布都保持清晰的布局关系。
- [x] 播放/暂停、进度定位和当前时间显示继续可用。
- [x] 控制栏操作、时间轴定位、页面当前帧和 Remotion Player 保持同步。
- [x] 控制栏不会造成全局页面滚动或破坏横屏、竖屏画布的等比显示。
- [x] 现有预览和导出共用 `EditorComposition` 的原则不变。

## Out of scope

- 音频剪辑、音量控制和音频波形编辑。
- 倍速、循环播放、逐帧控制等高级播放能力。
- 修改项目画布比例或导出分辨率。
- 修改视频内容本身及特效渲染逻辑。
