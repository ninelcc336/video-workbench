# 10 — 简化项目与工作区导航

**What to build:** 让编辑页只承担“选择和编辑项目”的任务，把工作区切换移动到启动页或设置入口，降低用户对项目与存储容器关系的理解成本。

**Blocked by:** None — can start immediately

**Status:** wontfix

- [ ] 编辑页只显示一个清晰的项目选择入口，不再同时显示项目选择和工作区选择两个同级控件。
- [ ] 当前工作区以只读名称或轻量状态信息展示，不让用户误以为它是另一个编辑项目。
- [ ] 用户仍可以在编辑页完成项目的新建、打开、重命名和删除；不提供复制编辑项目。
- [ ] 用户可以从启动页或设置入口选择最近使用的工作区、打开其他本地工作区或创建新的工作区。
- [ ] 切换工作区后重新加载该工作区的项目、视频素材、个人预设和视频模板。
- [ ] 切换项目或工作区前，对尚未自动保存的编辑显示明确提示，并提供继续切换或返回编辑的选择。
- [ ] 工作区打开失败时保留当前编辑项目，不静默切换到空项目，并显示重试或恢复入口。
- [ ] 覆盖项目选择、工作区切换、未保存提示和错误恢复的组件测试与浏览器验收测试。
- [ ] 不改变项目与共享视频素材的引用关系：删除项目不级联删除素材，删除被引用素材仍需阻止。
