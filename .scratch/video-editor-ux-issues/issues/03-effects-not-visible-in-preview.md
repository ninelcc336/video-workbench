# 添加弹入卡片和漂浮气泡后，特效在预览画面中不可见

Category: bug  
Status: resolved

## Summary

修复特效片段已经加入编辑项目但未在实时预览中呈现的问题，至少覆盖“弹入卡片”和“漂浮气泡”两个内置特效模板。

## Current behavior

用户从左侧模板库添加“弹入卡片”或“漂浮气泡”后，时间轴和特效参数面板可以看到对应片段，但用户反馈视频画面中没有看到特效。

现有组合定义会遍历 `effectClips`，根据模板身份创建 `Sequence`，模板注册表中也已经注册了这两个模板。因此需要区分是当前帧不在片段有效范围、入场动画首帧透明、Player 没有更新项目快照，还是模板层实际没有绘制。

## Desired behavior

只要当前帧落在特效片段的有效范围内，模板视觉内容就应叠加在视频上方；在片段的可见动画阶段，卡片和气泡都应清晰可辨，并与时间轴起止帧一致。

## Acceptance criteria

- [ ] 在有视频素材的项目中添加“弹入卡片”，定位到其有效范围内的非首帧时，卡片可见且位于视频上方。
- [ ] 添加“漂浮气泡”后，在其有效范围内可以看到气泡，且气泡会随帧变化产生漂浮动画。
- [ ] 特效片段在有效范围外不显示，不影响其他视频片段。
- [ ] 特效的 `fromFrame`、`durationInFrames` 和模板入场动画使用同一帧基准。
- [ ] 至少有一个自动化测试验证两个模板通过真实注册表和编辑项目快照能够生成可渲染的特效层。

## Out of scope

- 设计新的卡片或气泡视觉样式。
- 增加新的特效模板类型。
- 处理参数控件修改后不刷新的问题；该问题单独记录在 issue 04。

## Related implementation concepts

- `EffectClip.fromFrame` / `EffectClip.durationInFrames`：特效片段有效时间范围。
- `TemplateDefinition.render`：模板视觉渲染契约。
- `EditorComposition`：将视频层与特效层组合到同一预览和导出定义中。
